# 0.7.5 —— 文字像人写的，版面像真书

> 这一版只做两件事：把「识图生文」的文字与标题从「AI 味」里拉出来，
> 把导出与界面的排版收尾到能当书看的程度。

## 一、标题：先试三个，只交一个

过去的标题问题不是「不好听」，而是**一眼能看出是机器取的**：四到八个字，中间塞一个「的」，
前后各挂一个空泛词（时光、温柔、岁月、之间、远方、答案）。

现在提示词里写死了六种可用手法，写之前必须先在草稿里试三个候选，只交一个：

| 手法 | 长什么样 | 例子 |
| --- | --- | --- |
| 器物 | 画面里一件具体的、能叫出名字的东西 | 第三根电线杆 |
| 刻度 | 一个时刻、一个读数、一个数量 | 六点二十 |
| 反差 | 两件互相不对付的事并排 | 亮着的店，关着的门 |
| 痕迹 | 人刚走过留下的那一点证据 | 刚拧干的抹布 |
| 动作残留 | 事情发生过，但人已经不在了 | 回头之前 |
| 招牌地名 | 画面里的字、路牌、门牌 | 往右五十米 |

硬规则：4 到 10 个字，不用「的」开头或收尾，不加书名号引号。
`TITLE_BANNED_WORDS` 从 12 个扩到 28 个，`src/config/styles.ts` 里每一种风格从「一句形容词」
改成了「具体怎么写 + 两个例子」——选「文学」不会再只回你四个字。

## 二、正文：不许起手就报幕

`src/config/prompts.ts` 升到 **v7**，光给规则不够，这次的改法是**把句式当菜单**：

- 五种句式：证据句 / 在场句 / 对照句（全篇最多一次）/ 痕迹句 / 收束句（停在物件上），至少用三种。
- 硬指标八条：两处可核对的具体物、一处别人容易漏掉的小细节、至少一句不超过 8 字且一句不少于 25 字、
  比喻最多一处且禁用「仿佛／似乎／宛如／犹如」、不写画面外、不解释意义、不用感叹号、
  **同一批书里以时间开头的不得超过三分之一**。
- `HUMAN_TONE_BLACKLIST` 新增「AI 结构词」：进行、使得、从而、进而、不难发现、值得一提、整体来看、
  可以看出、给人一种……的感觉、画面感、叙事感、情绪张力、构成了……的对比、形成了呼应。
- 正反例从 5 组扩到 10 组，交付前自检清单重写为 10 条（第 1 条就是「先写三个候选」）。

## 三、模型之外再加一道确定性润色

新建 `src/lib/ai/polish.ts`，**不改写内容、不新增信息**，只做机器能保证的收尾：

- 标题：去引号书名号句读 → 剔空泛词 → 超 10 字在标点／「的」／「与」处断 → 4 字以下从正文里捞物件名兜底
  （`rescueTitleFromStory()` 先用偏正短语 `2-4字 + 的 + 2-4字` 找，再逐字剥掉动词尾巴）。
- 正文：去「在这张照片中／画面中」这类报幕词，把「仿佛／宛如／犹如」换成「像」，
  删掉「时光／岁月／治愈／氛围感／高级感」，`进行＋动词` 还原成动词，统一全角标点、去掉感叹号。
- **套话只摘词不删句**——教训：整句过滤会把「值得一提的是，画面里的车流很多」删成空字符串；
  摘完若整句空了，回退到只清标点的原文。
- 先修正文再修标题（标题兜底要用已修正的正文，否则会捞出「在这张照片中」当标题）。
- `scanTextQuality()` 给每篇打 0 到 100 分并列出问题，`normalizePhotoAnalysis()` 把改了什么写进警告。

实测（`.devtools/check-polish.ts`）：

| 原文 | 修正后 |
| --- | --- |
| 《时光里的温柔》 | 夕阳的余晖 |
| 在这张照片中，夕阳的余晖……这一刻，光影交错… | 夕阳的余晖洒在街道上，像为这座城市披上了一层金色的纱……这会儿，光影交错…… |
| 值得一提的是，画面里的车流很多。整体来看……进行观察之后…… | 画面里的车流很多。这座城市的交通很热闹。观察之后，光线的变化。 |

质检分 70 → 100。

## 四、导出排版：不许孤行、不许断图注

- PDF（`src/lib/export/pdf-design.ts`）：`.pg-title` 加 `text-wrap: balance` 与 118mm 上限（两行标题不再只剩一个字）；
  `.pg-story` 加 `orphans: 2 / widows: 2`（段落首尾不留孤行）；`.pg-head`、`.pg-cap` 不许跨页断开。
- Word（`src/lib/export/word-grid.ts`）：标题与序号段落加 `keepNext: true`（标题必须和照片同页），
  图注段落加 `keepLines: true`（不许从中间断开）。

## 五、界面排版的三处收尾

- 标题按词意均衡断行（`text-wrap: balance`），正文按词意收尾（`text-wrap: pretty`）。
- 数字统一等宽（`.ps-num` + `tabular-nums`），读数上下对得齐。
- 正文阅读宽度限制在 34 个汉字（`.ps-prose`），不用来回找行首。
- 项目书架不再等大九宫格：`ProjectCard` 新增 `featured`，第一本占两格、封面 16:9、书名用 `clamp(18px, 2.1vw, 24px)`。

## 六、怎么升级

装 `安装包/0.7.5/照片故事-0.7.5-安装版.exe`，覆盖安装即可；项目和照片都在本机数据库里，不会动。

老照片不会自动重写文案——想用上新提示词，去项目页点「一键重生成」（会消耗模型额度）。
