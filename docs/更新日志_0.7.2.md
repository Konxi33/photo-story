# 照片故事 0.7.2

> 一句话：照片墙从「一片空白」变成真的能看、能拖、能调大小；界面这一遍动起来了。

安装包：`PhotoStory-0.7.2-setup.exe`

---

## 一、照片墙为什么是空的

这是这一版最值钱的一条。

你反馈「照片墙效果是我想要的，但里面照片全是空白」，我一开始也以为是图片没加载。实测后发现不是：

- 方块里的 `<img>` 的 `naturalWidth` 是 640、`complete` 是 `true`、`opacity` 是 1 —— 图片一直在，像素也是真的。
- 问题出在建方块的那段代码：占位底板（`.ps-wall-cover`，一块近乎不透明的米色渐变）被排在了照片**之后**，于是它盖在照片上面。
- 所以视觉上你看到的是一堆「空的米色方块」，而浏览器里照片好好躺在它们底下。

改法只有一行顺序：`append(cover, img, veil, cap, ring, badge)`。

同一个问题还有两个帮凶：

1. **远处的方块只有四成不透明**（距离场 `opacityMin 0.4`），在米色纸面上几乎和背景同色，等于「看不见」。改成 `0.68`，缩放也从 `0.6` 提到 `0.74`。
2. **懒加载判断不到位置**。方块靠 `transform` 摆位，浏览器算「在不在视口」的时候不认这套位移，于是一圈空框要等你拖一下才出图。改成一律立刻加载。

还有一条：舞台的初始位置原来贴在世界原点（左上角），二十张照片全挤在左上角、右下大半空白，也被读成「照片墙没加载」。现在进页面就把视野对到墙的正中，并且**按方块尺寸对齐**再居中——不对齐的话上下各露出半排照片，顶上看就像一条脏边。

## 二、照片墙现在能调大小

照片库右上角多了一根滑块：方块从 **120 到 300** 随便推，松手就记住（存在 `ps:wall-size`），下次进来还是你选的尺寸。

- 改尺寸时已经在场上的方块会就地缩放并保持居中，不会跳一下再重排。
- 浮在墙上的那枚「按住拖动」提示去掉了，用法提示挪到页首一行图标胶囊里（按住拖动 / 滚轮缩放 / 双击看大图）。

## 三、照片库变成满屏工作台

以前照片库是一整页往下滚的长页面：页首大标题 + 说明书卡 + 分类 + 排序 + 墙面，加起来比一屏还高，墙面被挤到下面。

现在：

- 整页不吃滚动，墙面吃满剩下的视野（`h-[calc(100dvh-var(--header-h))]`）。
- 页首领成一行：小眉标 + 26px 衬线标题，右边是「20 张 / 共 20 张」与用法提示。
- 说明书默认收成一枚小按钮，分类 chips 与排序压成两行。
- 网格视图也跟着改成满高滚动，切回来不会把页面撑长。

## 四、侧栏三个毛病

| 你说的 | 真因 | 改法 |
| --- | --- | --- |
| 往下滑侧栏再点「更新日志」，侧栏瞬间弹回顶部 | 每个页面各挂一份 `AppShell`，换页时侧栏整个重挂载，`scrollTop` 归零 | 滚动位置记在模块级变量里，重挂载后夹到合法范围写回去 |
| 换页时下面「设置」那一坨会跳一下 | 底部用量条要等异步的存储统计才出现，出现时整块长高 24px，把导航顶上去 | 用量块先占坑（`min-h-[26px]`），没数据时是等尺寸的透明骨架 |
| 小滑条不够灵动，点「设置」时会重叠 | 「设置」在滚动列表之外，指示条跨大段时是一路滑过去的，视觉上压在别的项身上 | 距离超过 120px 时改成**就地淡出淡入**（200ms 弹簧曲线），只有小范围移动才滑过去 |

顺手把导航密度重排了一遍：条目 36px → 34px，组间距 20px → 14px，组标题下沿收紧。十一个入口一屏放得下，最下面的「回收站」不会再被切在缝里。

## 五、设置改完不用再切页面

以前在设置里改「功能栏悬浮展开」，点保存没反应，必须去别的页面再回来——因为 `AppShell` 只在挂载时读一次设置，之后没有任何通知机制。

现在：保存成功 → 派发 `ps:settings-saved`（带上完整的 `AppSettings`）→ `AppShell` 收到就应用：侧栏模式、折叠状态、外观一起换。

还有一个隐藏的一半：内容区的左内边距原来不管哪种模式都按栏宽留白，悬浮模式下侧栏本来浮在内容上面、不该占位。现在悬浮模式 `md:pl-0`，收起 / 展开各按自己的栏宽算。

## 六、深色主题的噪点

深色底上那层噪点原来是同样的不透明度（0.5），在近黑背景上就是「撒了一层白灰」。压到 **0.14**，并改用 `soft-light` 混合，只留一点点纸感。

首页那圈缓慢旋转的 conic 光圈在深色下也太重，压到 0.4。

## 七、界面与动效（这一遍真正在改的东西）

- **页首换骨**：每个页面的标题改成衬线展示体（`ps-serif ps-display`，28–44px 随视口走），序号改成铜色小方章。以前标题用无衬线、和卡片标题一个气质，看不出层级。
- **切页进度线**：内容区顶部一条 2px 陶土色渐变线，切路由时从左跑到右（620ms），比干等强。
- **滚动进场**：`.ps-reveal` 基于 `animation-timeline: view()` —— 内容进入视口时轻轻浮上来（位移 + 轻微模糊 + 透明度），纯合成器执行，不动主线程。首页的模块列表已经用上。
- **错峰**：`.ps-stagger > *` 给一组卡片排队进场（30–330ms）。
- **抬起**：`.ps-lift` 悬停位移 2px + 暖色投影。
- **滑块**：`.ps-slider` 全套自定义（4px 圆角槽 + 14px 铜色圆点，悬停放大 12%、按下 24%）。
- **滚动条**：改成鼠标移上去才浮现，平时透明——长列表不再被一条灰杠打断。
- 关掉系统动效时，这些动画都会跟着停（`prefers-reduced-motion` 与设置里的「界面动效」开关两条都生效）。

## 八、怎么升级

1. 打开旧版 → 设置页最下面「应用」→ 检查更新，或者直接运行 `PhotoStory-0.7.2-setup.exe`。
2. 覆盖安装即可，项目和照片都在本地数据库里，不受影响。
3. 升级后第一次进照片库，如果方块大小还是旧的，推一下右上角那根滑块就好。

## 九、下一步候选

- 照片墙加「按时间/按评分自动聚簇」，让墙自己长出疏密。
- 排版台把「哪页空着」标出来，直接拖照片进去。
- 导出时给整本书加一份 PDF 书签目录。
