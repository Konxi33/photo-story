# 照片故事 0.8.1

这一版补的是「改了跟改了一样」的那些地方：进项目没有转场、照片墙只能拖、翻页预览看完就忘。

## 进项目有门了

点书架上的卡片进项目，以前是一帧硬切：工作台不套普通页面的外壳，那套 3D 转场管不到它。

现在点下去先盖一层纸色帷幕（写着你打开的那一卷的名字，一道铜线拉开），进到工作台再从那里化开。从工作台退回书架同样有过渡，途中那一帧被帷幕接住，看不到白闪。

帷幕只做透明度和位移，不碰 `filter`——0.7.x「整页重拍、60fps 掉到 23」的坑不再踩。效果受设置里「动效 → 页面转场」的开关控制。

## 照片墙能放大了

- 滚轮缩放 0.55–1.9 倍，**以指针压着的那张为锚点**，放大时照片不会从脚下滑走。
- 工具条上出现百分比，点一下回到原尺度。
- 墙停下来时，指针压着的那张微微推近，像拿放大镜看底片。
- 键盘：方向键推墙（Shift 推得更远）、`+` / `-` 缩放、`0` 或 `Home` 回中、`Esc` 取消选择。

## 翻页预览：放映模式

按钮或 `F` 键进入放映：全屏只留纸页、页码和一行快捷键，给客户看稿时不必让对方看见软件界面。

- 点纸页往后翻，方向键照旧。
- 可以开「自动翻页」，每 4.2 秒翻一次；翻到最后一张停住，不绕回封面。
- `Esc` 退出，浏览器自己的全屏退出也会把放映层一起收起。

## 翻页预览会记住你看到哪

每个项目各记一份（`ps:flip:<项目 id>`），下次进来从原处接着翻；那几页要是被删了，会自动收到最后一页。

## 印张补白

印刷厂一张纸正反印四面，页数不是 4 的倍数，最后一叠就空着半张。翻页预览的工具栏多了「补白页」，末尾补 1–3 页空白凑整；导出 Word / PDF 有同一个开关，直接告诉你这一本会补几页。页数算法只有一份（`src/lib/book/signature.ts`），预览和导出不会对不上。

## 导出模板：整页大图

一页只放一张照片，顶到版心四边，不加图注；编号与标题收进书末附录，并自动打开补白页。适合做纯图册或送厂打样。

## 评审记录可以导出了

跑完三位评委，评审页右上角多两个按钮：

- **导出表格（CSV）**：编号、标题、文件名、平均分、分歧度、三位评委的分数与评语，一行一张。带 BOM，Excel 打开不乱码；按分歧度排序就知道哪几张争议最大。
- **导出阅读稿（Markdown）**：一段能直接发给别人的文字稿，按分歧从大到小排，评语按评委分行。

两个文件都在本机生成，不联网、不调模型，评语原文照抄。

## 小修

- 侧栏底部「设置」旁的细竖条不再压住「设置」两个字：上面导航列表留了 7px 给指示条，底部那块原来没留，现在对齐了。
- 开关更好按了：轨道还是 34×20，可点区域撑到 36px 高。

## 升级

下载 `PhotoStory-0.8.1-setup.exe` 覆盖安装即可。项目、照片、书稿都在本地数据库里，不会动。
