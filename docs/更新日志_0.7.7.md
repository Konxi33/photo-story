# 0.7.7 · 在项目里就能改怎么写，顺手把多余的东西收一收

发布日期：2026-11-25

这一版两件事：**把「怎么写」搬到项目里**，以及**把界面上多余的一圈圈边线收掉**。

## 一、项目顶栏多了「写法」

以前标题风格、叙事笔法、故事长度只在全局设置页能改。人已经在项目里翻照片了，发现这一批不该写得那么文艺，得先退出去改设置、再进来——这一版把它搬进来了。

点顶栏的「写法」：

- **先挑一种口味**：像图注（短、克制，只写画面里有的）、像随笔（有画面也有语气，中等长度）、像纪实（冷静、按时间线铺开）。点一下就同时设好三项。
- **标题**：六种风格各配一句「具体怎么写」，选完能看见它到底要什么，不是四个字标签。
- **叙事笔法**：照片随笔 / 冷静纪实 / 散文诗 / 日记体 / 短句硬朗。
- **故事长度**：短 80–120 字、中 120–200 字、长 200–300 字。

点「保存写法」，下一次生成就按新的来；**已经生成的照片不会自动变**，想变哪张就单独重写，或者用下面的批量修标题。

## 二、「更多」里多了「修一遍标题」

老版本模型留下的道具式标题（「副驾那只白摆件」「一圈白杆」「弯道白车」这类），不用整批重新生成——「更多 → 修一遍标题」会：

1. 用本地规则照出哪些标题是「某物 + 的 + 某物」的道具标签；
2. 从**这张照片自己的故事**里挑一句有局面的短句换上去；
3. 同批里已经用过的句子会跳过，避免两页一个标题。

菜单里直接写着「N 张像道具名」。全程不调模型、不花钱，故事和评分一个字不动。改完会告诉你改了几个、几个没找到合适句子（那几个建议单独重写）。

## 三、长标题不再硬挤

PDF 与 Word 用同一套口径，标题按字数自动降一档字号：

| 字数 | 字号 |
| --- | --- |
| 10 字以内 | 原尺寸（16pt） |
| 11–14 字 | 约 14.7pt |
| 15–20 字 | 约 13.1pt |
| 20 字以上 | 约 11.5pt |

标题不再把版面重心撑歪，也不会因为挤成两行把照片压矮。

## 四、界面降噪

用户反复说「太冗杂、太凌乱」。这一版不动结构，只把视线里的杂音降一档：

- 卡片描边淡一档，不再每张卡都顶一圈深边；
- 顶栏、工具栏这类浮条不再同时叠描边 + 阴影 + 毛玻璃，只留毛玻璃和一条发丝线；
- 次要说明文字统一压暗一档，不再一行行抢读；
- 顶栏那行「双击项目名可重命名」的提示收掉了（双击照样能用）。

## 怎么升级

下载 `PhotoStory-0.7.7-setup.exe`，覆盖安装即可，数据与 Key 都保留。

装完后建议先做两件事：①进项目点「写法」，把这一批的标题风格和长度定下来；②点「更多 → 修一遍标题」，把老标题里像道具名的那批一起换掉。

## 下一步候选

- 写法面板再加「参考已有的三张」：让模型照着你挑过的三张写法来写这一批。
- 修标题支持逐个确认（现在是一次批处理）。
- 排版台里给标题留字号档位，和导出的自动降档对齐。
