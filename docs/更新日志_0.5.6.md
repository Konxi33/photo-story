# 照片故事 0.5.6 更新日志

> 版本 0.5.6 · 2026-11-15
> 一句话：**删错了还能捡回来**，顺手把一批"每天都要用"的地方磨快了。

---

## 一、照片回收站（新模块）

以前点删除，照片和它的预览图、AI 原图会一起从本地数据库里消失，误删就没了。现在改成两步走：

| 操作 | 以前 | 现在 |
| --- | --- | --- |
| 删除照片 | 直接从库里删掉，图片资源一并销毁 | 标上删除时间，移进「回收站」 |
| 想找回 | 没有入口 | 侧栏「系统 → 回收站」，一键恢复 |
| 真不要了 | 只能删 | 回收站里「彻底删除」或「清空」，清空前二次确认 |

- 回收站列表显示：缩略图、标题（没标题就显示文件名）、来自哪个项目、什么时候删的，以及顶部合计占用空间。
- 项目里删完，toast 上直接给「撤销」，一点就回到原处，不用专门跑一趟回收站。
- **回收站里的照片不会出现在任何统计里**：项目、照片库、评分、摄影档案、主题馆、选片擂台、评审室、导出成书、翻页预览，全部自动排除。实现方式是数据库层默认过滤 `deletedAt`，不是每个页面各写一遍。

## 二、批量标签

选一堆照片 → 工具栏「更多 → 批量标签」，一张脸就能改完：

- **加标签**：一排输入，逗号、顿号、空格都能分隔，一次最多 8 个；
- **去标签**：把选中的照片里出现过的标签按次数排出来，点一下就划掉（比如把 20 张照片里重复的「#夜色」统一去掉）；
- **改氛围**：保持各自 / 已有氛围 / 安静 / 热烈 / 克制的怀旧 / 潮湿的夜色 / 轻快的日常。

标签会去重、保留原有顺序、最多 10 个；没有 AI 分析结果的照片会跳过并在提示里说明。

## 三、编排「呼吸页」

摄影集不能每一页都塞满照片。编排页新增「呼吸页」按钮：插一章**标题留空、只写一句题记**的内容，导出时就变成一页留白 + 居中一行小字 + 一条细线——书中间有喘息的地方，翻起来才不像资料册。

## 四、导出：印前提醒 + 方案预设

- **印前提醒**：对话框会自动数出「光线分低于 70」的照片，提示「有 N 张照片偏暗，纸面比屏幕更吃暗，印前把暗部整体提亮 2~3%、黑色别压到纯黑」。这是印刷厂每天都要交代的那句话，现在软件自己说。
- **方案预设**：一套排版选项可以取个名字存下来（默认名如「A4 双栏 · 带图注」），下次换项目一键套用；同名覆盖，最多 12 套，选中的方案可以删除。

## 五、更快找到那张照片

命令面板（Ctrl + K）现在除了页面和项目，还能**搜照片**：输入标题或标签，命中后直接跳到那张照片所在的详情页。跳过去的地址参数用完即擦，刷新或后退不会重复弹窗。

## 七、修掉的问题

| 问题 | 原因与修法 |
| --- | --- |
| 编译不通过（呼吸页） | 呼吸页用了不存在的 `WORD_FONTS.body`，改用 `coverSubtitle` 样式 |
| 批量删除时内存占用高、明显卡顿 | 旧的可撤销实现会把整张原图复制进内存当快照；改成软删除后彻底移除这套快照逻辑 |
| 误删无法恢复（真 bug） | 旧实现硬删除并连带删掉资源文件，本次改为回收站 + 彻底删除 |
| `?photo=` 刷新会重复弹详情 | 打开后 `history.replaceState` 清掉参数 |

## 八、怎么升级

1. 运行 `照片故事-0.5.6-安装版.exe`，安装器会覆盖旧版本，**照片、项目、评分、编排都保留**（数据在 `%APPDATA%\photo-story\`，不在安装目录）。
2. 如果之前在设置里固定过导出文件夹，升级后仍然有效。
3. 从这一版起只提供安装版，不再出便携版。
