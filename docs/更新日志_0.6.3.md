# 0.6.3 · 印出来是书，不是草稿

这一版主要解决一件事：**导出的 Word / PDF 要能直接拿去印。**

## 一、Word 导出整页重做

### 以前为什么字会压在一起

单页版面是用「12 列 × 24 行」的表格铺出来的：一格放照片，一格放拍摄手法，一格放评分卡。为了保证每一页的高度不超，表格行高写死成「固定值」。

问题在于：**Word 的「固定行高」并不会裁掉超出这个高度的内容**，它只是不再把行撑高。于是行内文字一多，就从格子里溢出来，压到下面那一块的字上 —— 屏幕上看到的就是标题叠在照片上、评分卡压在正文里。LibreOffice / WPS 也一样的表现。

另一个后果是整块被顶走：表格总高比一页多半行时，最后那行被推到下一页，前一页只剩一条白。

### 现在怎么排

Word 现在**不用网格了**，走单栏流式：

- 纯段落、零嵌套表、零固定行高 —— 字多字少都由 Word 自己往下推，不可能压住。
- 顺序固定为：章头 → 照片序号 → 标题 → 照片 → 图注 → 拍摄手法 → 正文，然后次要块（评分卡、为什么好看、参数、机身、标签、氛围、无障碍描述）。
- 一页塞不下就自己翻页，不会再出现「表格比页高一点」引发的整页白纸。

### 照片能占多大，是算出来的

每张照片先按「这一页还要印多少字」算一遍：文字多，照片就收一点；文字少，照片就长高。所以不管正文写了 80 字还是 280 字，图和字始终在同一页上。

实测：同一份 20 张照片的项目，从 37 页压到 **25 页**，一页一张照片，PDF 渲染后逐页看过，没有叠字、没有半页空白。

### 实在放不下时，谁让位

按这个顺序依次省掉：**无障碍描述 → 氛围 → 类别 → 为什么好看 → 拍摄参数 → 机身信息 → 标签 → 总分**。

正文和「拍摄手法」一定保留 —— 那是这本书的骨肉，评分卡是给编辑看的，先让。

### 章头后面那张白纸

分页段落在章头已经分过页时不再重复插入。以前每章都多吃一整张白纸，一本 17 章的书白白多印 17 页。

## 二、PDF 修好了

PDF 之前有两个问题，都是它自己的那套代码没跟上：

1. **版心算错**：把 cm 当 mm 用，实际版心比 Word 宽出 8mm —— 右栏内容顶到纸边，被裁掉。现在 PDF 与 Word 共用 `metrics.ts` 里的同一套边距，两边的正文宽高完全一致。
2. **格子里装不下的字会溢出到下一块**：PDF 的格子高度是按画布算死的，拍摄手法、点评这类文字多的块如果超出格子，字就压在下面的正文上（实测「字错乱」）。现在每一块在画之前都按格子真实宽高再裁一次：装不下就先丢「后期」这类次要行，再不行才截断加省略号，绝不允许溢出压住别人。

## 三、导出能自己定了

以前导出只有一个「排版密度」在调，字体、纸色都定死。现在：

| 项目 | 选项 |
| --- | --- |
| 正文字体 | 宋体 / 黑体 / 楷体 / 仿宋 |
| 纸张 | 纯白 / 象牙 / 浅灰 / 夜色 |
| 卷首语 | 可写一句话，也可以留空 |
| 后记 | 同上 |

标题统一用微软雅黑 —— 宋体标题笔画太细，小字号印出来发虚；雅黑在 14pt 以上字重清楚，又不像 Arial 那么洋气。

**相框里已经烧进去的参数不会再印一遍。** 用相框导出的照片，屏幕上就带着相机型号、光圈、快门，导出时导出器能检测到这一点，自动省掉「拍摄参数」「机身信息」两块，把版面让给正文。

## 四、排版台终于拖得动了

之前拖动没有反馈：拖到一半松手，积木弹回原位，看着像软件没反应。现在：

- 拖到放不下的位置（和别的积木重叠、或小于最小尺寸），画布上会亮起**红色虚线框**并标「这里放不下」，松手前就知道放不进去。
- 松手后如果真的放不下，积木回到原位并提示原因，不会静默失败。
- 选中的积木左下角显示 `3 列 · 5 行 · 8×10` —— 第几列、第几行、几格宽几格高，写在纸上也好对照。
- 画布下面补了一行操作说明：拖动改位置、拉右下角小方块改大小、方向键微调一格。

## 五、界面上那些「差一点」的地方

- **侧栏滑条**：那条跟着选中项走的小竖条以前压在选中块的圆角上，还和文字贴边。现在挪进左侧一条独立窄缝（距左 2px、宽 2.5px），和选中块的间距 2.5px，上下完全对齐。
- **小按钮点不中**：评分页的「查看详情」「重新评分」原本只有 18px 高，点了没反应多半是没点准。现在上下各撑开 4px，可点范围翻倍。
- **编排页的把手**：拖动把手、上移/下移/删除、从本章移除都加大了一档，鼠标不用瞄准。
- **存储占用条**：项目页底部那条进度，占比极小时只剩一个像素宽，看着像掉了字符。现在最小 4px，永远看得见是个条。

## 六、怎么升级

安装包：`安装包/0.6.3/照片故事-0.6.3-安装版.exe`

直接覆盖安装，项目、照片、评分都在 `%APPDATA%\photo-story\data`，不会被覆盖。

## 七、下一步的候选

- 排版台的自定义坐标目前只作用于 PDF：Word 为了「字不压字」改成了单栏流式。如果之后要做「Word 也按画布排」，需要换一条实现（比如把每块渲染成无边框的单格表并用 `cantSplit` 锁死），风险高，先记在这里。
- 导出对话框里的「密度」与新的字体/纸色设置可以考虑合并成「样式预设」：一套名字 = 字体 + 纸色 + 行距 + 密度，选名字就行，不用逐项调。
