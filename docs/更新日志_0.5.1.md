# 照片故事 0.5.1 更新日志

> 版本号：0.5.1　发布日期：2026-11-13
> 一句话：**慢一点，好一点。**

这一版没有加新按钮，只做三件事：把动效统一、把界面里的杂乱收掉、把深浅两套主题都调到能久看。
顺带修掉了几个「一直在那儿、但没人报」的老毛病（比如设置页分段控件首次进入不显示选中块）。

---

## 一、动效：整站统一

### 1. 一套缓动、一套时长
所有进入、悬停、弹窗、面板、骨架屏都改用同一组 `--dur-*` / `--ease-*` 变量。
以前是「有的地方 120ms、有的 400ms、有的干脆瞬移」，现在节奏一致，翻页不再一顿一顿。

### 2. 图片淡入（新增 `FadeImg`）
缩略图先用骨架占位，加载完再淡入（520ms）。
照片墙、评分页、项目封面、首页最近项目全部换过，滚动时不再一张一张「啪」地跳出来。

### 3. 侧栏指示条彻底稳了
底部存储占用是异步返回的，回来时会把「设置」项顶高 34px，而指示条停在旧位置。
现在指示条持续校正 + 监听尺寸变化，尺寸一变就重新落位。

### 4. 弹窗 / 面板 / 抽屉
统一 `ps-dialog-in`、`ps-sheet-in`、`ps-pop-in`，背景遮罩淡入淡出，关闭也有过渡，不再瞬间消失。

### 5. 减弱动效
系统里开了「减少动画」时，18 类动画全部自动关掉，只留淡入。

---

## 二、界面：去杂乱

### 6. 照片库改成时间线版式
左侧竖排日期（今天 / 昨天 / 11月6日 周四），右侧照片按固定尺寸铺开。
以前按天分组是「每组占满 6 列」，某天只有 1 张时照片缩成 1/6 宽、右边一大片空白；
现在某天只有 1~2 张时照片自动放大一档，读起来像相册的时间线。

### 7. 设置页控件统一
「服务商 / 评分方式 / 主题模式 / 字体 / 左侧功能栏」五组全部换成同一款分段控件（滑动药丸）。
以前是两组分段控件 + 三组裸按钮，同一页里三种样子。

### 8. 侧栏底部分区
导航与「设置 + 存储 + 版本」之间加了一条细线，版本号不再贴着窗口底边。

### 9. 首页杂志封面式双栏
左刊头（缺笔字标题 + 说明 + 三个入口），右最近项目清单。
中段那块约 250px 的空白没了，只有一个项目时右列也不至于空荡。

### 10. 工作台工具栏收成一行
批量生成 / 全选·反选 / 搜索 / 更多 / 视图 / 列数 / 筛选，次级操作全进「更多」。
上传区在已有照片时收成一条窄栏，首屏多出一行照片。

### 11. 状态栏与提示条
- 空闲时不再挂一根 0% 的进度条，改为「全部就绪」；
- 提示条补了深色变体，不再在深色下弹一块刺眼的米黄；
- 提示气泡跟随主题（以前硬编码浅色，深色下弹白条）。

### 12. 文案对齐
「导出 Word」改名「导出成书」——它其实支持 Word / PPT / PDF。

---

## 三、浅色主题调校

### 13. 纸白 + 细线
背景从纯白改成微暖纸白，分隔线降到 6% 墨色，长时间看照片不刺眼。

### 14. 选中态
分段控件的选中块在浅色下是深墨色药丸 + 白字，对比度足够但不跳。

### 15. 图片边框
浅色下照片描边从纯黑降到墨色 8%，不再像贴了一圈黑框。

## 四、修掉的 bug

| 问题 | 原因 |
| --- | --- |
| 设置页分段控件首次进入不显示选中块 | 首帧测量时子元素还没注册，量不到就再也不量了；改成逐帧重试 |
| 深色模式下提示气泡是白底黑字 | 硬编码 `theme="light"`，改成跟随 `data-theme` |
| 设置页并发上限被夹在 4 | 保存时写死 `Math.min(4, ...)`，改为 1–50，选项也补齐 |
| 评分分布直方图一根柱子都看不见 | 柱子高度百分比没有参照高度 |
| 照片库分类 chip 行被右侧切断 | 补了渐隐遮罩 |
| 窄屏顶栏图标进项目详情后不高亮 | 改成前缀匹配 |
| 工作台未配密钥的提示条深色下过亮 | 补 `dark:` 变体 |
| 照片墙滚动时图片「啪」地跳出 | 改骨架 + 淡入 |

## 五、怎么升级

1. 关闭正在运行的照片故事；
2. 双击 `照片故事-0.5.1-安装版.exe`，一路下一步（会覆盖安装，项目和照片都在）；
3. 打开后版本号显示 `v0.5.1` 即成功。

> 便携版 `照片故事-0.5.1-便携版.exe` 免安装，双击即用，适合放 U 盘。

数据都在本机（IndexedDB），升级不会丢照片与文案。
