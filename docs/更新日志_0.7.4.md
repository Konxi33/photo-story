# 0.7.4 —— 把上一版没擦干净的地方擦一遍

> 0.7.3 是一次结构级换版（首页、顶栏、评分、设置、工作台都动了）。这一版只做修补：
> 把换版之后露出来的边角对齐，顺手补两处小东西。

## 一、内容不再贴窗口边

选了「悬浮展开」侧栏模式后，内容区的左内边距被收成了 0（这是 0.7.2 为了让侧栏真正浮起来做的），
结果**没自带内边距的页面就贴到了窗口边缘**——排版台的标题「这一页，你自己摆」被切掉了半个字。

- `src/components/app-shell.tsx`：悬浮模式改成 `md:pl-[var(--shell-gap)]`，留一条正常的呼吸边。
- `src/app/studio/page.tsx`：补上自己的 `px-5 py-6 md:px-8`（其余页面早就各自带了）。

## 二、颜色对齐

项目卡封面底部那条生成进度原来是**亮绿**，在这套陶土色里像贴错了标签。

- 成功段 `bg-emerald-400` → `bg-copper/90`；失败段 `bg-red-400` → `bg-rose-400/80`。
- 卡片底部「全部完成」的小圆点同步改成铜色。

## 三、两处小补

- **项目列表末尾补一块虚线「新建一本」**：只有一两个项目时，右边不再空半格，新建也少点一次。
- **命令面板加「最近打开」**：AppShell 每次导航把当前页写进 `localStorage['ps:recent-pages']`（最多 5 条），
  Ctrl+K 打开时排在最上面一组，重复的页面不再在下面重复出现。

## 四、怎么升级

装 `安装包/0.7.4/照片故事-0.7.4-安装版.exe`，覆盖安装即可；项目和照片都在本机数据库里，不会动。

## 五、下一步候选

- 排版台的积木面板还没做拖拽缩略图，可以先补
- 照片库网格视图在几百张时该做虚拟滚动
- 命令面板可以再加「设置项直达」（搜「并发」「超时」直接跳对应小节）
