# 照片故事 0.5.7 更新日志

> 版本 0.5.7 · 2026-11-17
> 一句话：**这一页印什么，你说了算** —— 把一本书的一页拆成十四块，你拖成什么样，它就印成什么样。

---

## 一、一页印什么，你自己拼

以前每一页的顺序是写死的：序号、标题、图、图注、正文、参数、评分、建议、拍摄手法、标签、氛围。你只能开关，不能改顺序，也没法让一页只放"图 + 一行字"。

这次把它拆成了 **14 个板块**，每个板块都能拖、能加、能去掉：

| 组 | 板块 | 说明 |
| --- | --- | --- |
| 版面 | 序号 / 标题 / 图片 / 图注 | 图注还能选「编号 + 标题」「编号 + 参数」「标题 + 参数」或「不印」 |
| 文字 | 正文 / 机身信息 | 机身信息是新增的：机身、镜头、拍摄时间、曝光一行 |
| 解读 | 参数 / 评分 / 改进建议 / 拍摄手法 / 类别 / 标签 / 氛围 / 无障碍描述 | 类别是新增的：默认取第一个标签，没有就取氛围 |

- 拖左侧手柄改顺序；右下角「加一块」把没印上的板块加回来；每一行右边的减号是"这页不印它"。
- 顺序一变，页面上真正印的东西就跟着变 —— Word 与 PDF 走的是同一套板块定义（`src/lib/export/blocks.ts`），不会出现"Word 里排好了、PDF 里顺序不对"。

## 二、六套固定模板

不想一块块摆？点一下就整套换：

| 模板 | 用在哪 | 印什么 |
| --- | --- | --- |
| 摄影集 | 打印成书 | 序号、标题、图、图注、正文 —— 图最大，留白最多 |
| 参赛投稿 | 投比赛 | 再加类别、评分、改进建议，评委一眼能看到你的自述与得分 |
| 技术档案 | 给同行看 | 再加机身信息、参数、拍摄手法，评分也印上 |
| 极简画册 | 最省钱 | 只有图 + 一行图注，一页一张 |
| 图文随笔 | 旅行日记 | 标题、图、图注、正文、标签、氛围 |
| 完整档案 | 信息最全 | 十四块全印，图会被压小 |

模板套用后会立刻写进设置，你也可以在模板基础上继续拖 —— 拖过之后模板名就不再高亮，表示"这是你自己改过的版本"。

## 三、一张照片和它的文字，永远在同一页

这是这次改动里最费功夫的一件：

- **Word**：这一页的所有段落被串成一条「不可分割」的链（除最后一段外每段都设 `keepNext`），这一页开头那一段自带 `pageBreakBefore`。以前的做法是先插一个分页段落再排版，一旦内容刚好装满，分页段落自己会被挤到下一页，于是多印一整张白纸 —— 现在不会了。
- **PDF**：每页加 `break-inside: avoid`，Chromium 打印时整页整体下移，不会把图留在上一页、说明甩到下一页。
- 顺带把「图注」「标题+分隔线」也粘在下一块上：标题不会孤零零留在页底。

**代价与取舍**：如果一页的内容实在太多（例如把十四块全打开、正文又很长），Word 会把整页推到下一页，而不是拆开 —— 这时候页面上会出现一块空白。所以页面拼装里做了试算提示（见下一条）。

## 四、拼装时会实时试算

拖动的同时，对话框会拿一张真实照片算一遍：

> 试算：图片最高约 9.8cm，整页填充 86%。一张照片连同文字只占一页，不会被拆到两页。

如果装不下，会直接点名：

> 按这个顺序排，最近那张照片的「氛围」放不下，导出时会自动省掉 —— 想全留着就少勾几块。

省掉的顺序是有讲究的：**无障碍描述 → 氛围 → 标签 → 机身信息 → 类别 → 评分 → 改进建议 → 正文**。图片永远最后才让位，最小也留 6.6cm 高 —— 再小就不像一张照片了。

## 五、文案跟着版面走

这一条是把「排版」和「AI 写东西」接起来的：

以前不管你选什么版式，模型都按同一套字数区间写（80–200 字）。结果你要极简画册，它给你写两百字，印出来要么挤爆、要么你手动删。

现在导出设置会把版面翻译成一句提示词要求传给模型：

- 这页不印正文 → `story` 只写 1 句，30–50 字；
- 这页还要印参数 / 评分 / 建议 → 正文收在 90–130 字；
- 这页只有图与图注、留白多 → 允许写到 120–180 字；
- 这页不印拍摄手法 → 构图、光线不必在正文里复述；
- 会印无障碍描述 → 正文避免与它重复。

实现是 `src/lib/export/blocks.ts` 的 `pageHint(settings)`，批量生成与「一键重生成」都会带上它。

## 六、自动更新

每次打开软件 6 秒后，后台去 GitHub 查一次有没有新版本（`Konxi33/photo-story` 的 Releases）：

- 有新版本：右下角弹出提示，写清版本号与更新说明的前几行，点「去看看」跳到设置；
- 设置里新增「版本更新」一节：当前版本、最新版本、检查按钮、下载进度条、下载完成后直接调起安装包；
- 默认每次启动都查一次，也可以在设置里关掉；
- 网络请求走 Electron 的 `net` 模块（不用 Node 的 `fetch`）—— 这台机器的证书链被中间设备接管过，`fetch` 会直接失败，`net` 走的是 Chromium 网络栈，能正常连 GitHub；
- 只为 `github.com/Konxi33/photo-story/releases/download/` 开头的地址下载，其它地址一律拒绝；
- **踩到一个坑**：一开始用 `releases/latest`，实测返回 `latest=0.3.0` —— GitHub 的「latest」是「最近创建」而不是「版本号最大」，补建旧版本 Release 会把指针改回去。改成拉 `releases?per_page=30`，过滤 draft/prerelease 后按语义化版本取最大值，实测立刻正确识别 `latest=0.5.6`（当时本机装的是 0.5.7，所以显示「已是最新」）。

## 七、评分：让不同模型说出同一个分数

同一条照片用不同模型评，以前能差十几分 —— 因为每家的"刻度"不一样。这次加了一层校准：

- 每个模型先按自己的历史分布拉回同一条基线（DeepSeek 78 / 智谱 70 / OpenAI 85 是各自的"中位片"打出来的分），再按分段线性曲线映射到统一刻度；
- 校准完再与像素分加权，权重不再是固定的 60/40，而是看两家"握不握手"：模型分与像素分接近时模型权重升到 0.5，差得远时降到 0.2；
- 修掉一个老毛病：光线分以前是「模型 35% + 像素曝光 65%」，而像素曝光已经通过 `objective` 进过一次总分，等于同一件事扣两遍；现在改成 55/45；
- 评分提示词升到 **score-v4**：明确「赛事评审分不是鼓励分」，六个维度各给 60 / 75 / 85 / 95 四档锚点，要求跨模型同一张照片只许差 2–4 分，评审室三位评委之间分差不超过 4 分。

用模拟数据验证：同一张照片被三个不同"刻度"的模型打成 62 / 70 / 79，校准后是 70.5 / 70.5 / 72.7，极差从 17 分降到 2.2 分。

## 八、文案提示词 v6

按获奖图注、参赛自述的笔法重写：

- 标题 4–10 字，必须能指认画面里的具体东西；
- 正文三句固定分工：第一句可核对的事实 → 第二句一个动作或变化 → 第三句一句不肯定的判断；
- 结构硬指标 8 条（≥2 处可核对具体物、至少一句 ≤8 字、结尾不许抽象名词…）；
- 新增两组「反例 → 正例」，比讲道理管用。

## 九、修掉的问题

| 问题 | 原因 | 现在 |
| --- | --- | --- |
| 内容刚好满页时多印一张白纸 | 分页段落被挤到下一页 | 改成「这一段自带 pageBreakBefore + 整页 keepNext」 |
| 标题和细线留在页底、照片跑到下一页 | 分隔线没粘住下一段 | `dividerParagraph` 默认 `keepNext: true` |
| PDF 里照片页被拆成两页 | 只有元素级 avoid，没有页面级 | 加 `.page.figure-page { break-inside: avoid }` |
| 底板式导出的页面顺序改不了 | 顺序写死在代码里 | 全部走 `resolveBlocks(settings)` |
| 光线分重复计分 | 像素曝光既进 objective 又进 lighting | 权重改 55/45 |
| 自动更新永远说「已是最新」 | `releases/latest` 按创建时间取，补建旧版本后指针被改回 v0.3.0 | 拉列表后按语义化版本取最大 |
| 相框水印印出「推测 135mm」「ISO ISO 200」 | canvas 水印直接拼 AI 原始参数，没走图注那套规格化 | `paramLine` 改用 `tidyParam`，与图注同口径 |

## 十、怎么升级

1. 关掉正在运行的照片故事；
2. 跑新的安装包（0.5.7），装到同一个目录即可，项目和照片都在原地，不受影响；
3. 打开后如果看到右下角"有新版本"，说明自动更新已经能连上 GitHub 了。

老项目不需要任何迁移：以前的导出设置会自动翻译成等价的板块顺序（`legacyBlocks`），打开后版式和 0.5.6 完全一致，想改再改。

## 十一、这一版没做、下一步想做的

- 跨页大图（一张照片占满左右两页）与镜像页边距（内白 > 外白）；
- 页面拼装里支持"两页一组"的模板；
- 自动更新支持增量下载（目前每次下载完整安装包，约 82 MB）；
- 评分校准的系数目前是按经验给的，等积累了你自己的评分样本，可以做成"按你的口味再校一次"。
