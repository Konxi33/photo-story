# 照片故事 0.8.3 — 导出就是印出来的样子

这一版把「导出的 PDF / Word」修成印刷厂能直接用的样子。没有新功能，全是排版上的硬问题。

## 照片页不再「半页白」

- 竖构图照片能长到接近整页高（以前被压到版心的 46%）。
- 横构图按纸宽铺满，剩下的高差由上下留白平分，不再全堆在页脚。
- 标题 → 图 → 图注 → 正文当作一整块在版心里居中。

## 去掉两处重复

- 标题左边的浅灰小数字（`01`）删掉了。
- 图下那行重复的标题删掉了，图注只放图注该有的东西。

## 纸面底色铺满整张纸

以前选米白，只有版心那一块是米白，四周还是打印机的白。现在 `@page margin: 0` + 每页自带纸色与内边距，
从边到角都是一个颜色。积木版式（排版台摆的那种）也终于吃「照片圆角」设置。

## 日期可关、序号开关生效

导出对话框新增 **「封面印日期」**；关掉后封面只留书名与张数。**「显示序号」** 现在照片页与总览都听它的。

## Word：不再图字分页，也不再夹白纸

- 照片高度改成「这一页剩下的高度」，文字多了先让次要段落让位，不会把照片推到下一页。
- 总览页尾部的分页符与照片页分页叠在一起会夹出一整张白纸——这是「直接不同一页」的真因，已修。
- Word 也支持纸色（米白 / 浅灰；墨黑不铺，会印成一片糊）。

## 已知限制

- Word 不支持图片圆角（docx 格式限制）；PDF 正常。
- Word 总览缩略图仍按原始画幅缩放，竖图偏窄，暂未裁切。
- 真正的跨页大图仍未做。

## 升级

设置页「检查更新」，或直接下载 `PhotoStory-0.8.3-setup.exe` 覆盖安装。项目与照片都在本地。
