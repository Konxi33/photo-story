# 照片故事 0.8.4

这一版只做一件事：**让导出来的文档跟排版台里看到的一样**。

## PDF：照抄排版台的 12×24 画布

- 标题整行、照片占你摆的那几行、正文/评分/参数/拍摄手法各回各的格子。以前导出会重排一遍，所以位置永远对不上。
- 每个文字板块有细框和左上角标签（正文／评分／参数／EXIF／标签／氛围／无障碍／拍摄手法）—— 一眼分得清哪块是哪块。
- 纸面底色**铺满整张纸**，包括页边距。之前两个 bug 叠着：导出对话框没把「纸面底色」写进设置（选米白也永远打纯白），以及打印时还留着纸边距只给内容区上色。
- 章节标题是日期时不再印页顶那行章头 —— 那行字就是「每一页顶上都有一行日期」。
- 张数编号全清：照片左上角的 01/02、图注前的「— 图 01」、总览缩略图下的「01 · 标题」。
- 真实项目：22 页，审计 `clipped/outside/badBreaks` 全 0。

## Word：40 页 → 22 页，一图一文同页

- 一张照片连同标题、类别氛围、正文、评分落在同一页；照片高度按「这页剩下的高度」算，不再固定 60% 页高把文字顶到下一页。
- 不再出现「只印着拍摄手法」的空白页。
- 说明：Word 不再试图复刻 12×24 画布 —— docx 表格撑不住「整行标题 + 跨 10 行图片 + 精确行高」，要 1:1 还原请用 PDF。
- 米白以 `w:background` 写入；Word / WPS 显示正常，LibreOffice 系转换工具会忽略背景。

## PPT：布局尺寸修正

- `pptxgenjs` 的 `LAYOUT_16x9` 实际是 10×5.63 英寸，代码却按 13.333×7.5 排，导致图片比框宽、右栏文字跑到幻灯片外被裁。改用 `LAYOUT_WIDE`。
- 右栏改成游标式排版（标题 → 参数 → 正文 → 总分 → 要点 → 技术档 → 标签），不再叠字；封面补上第一张照片；底色跟着纸面底色走。

## 记住上次的导出设置

导出时会写回项目，下次打开对话框直接回填：纸面底色、圆角、页边距、各个开关。

## 验证

- 用真实项目（20 张、17 个日期章节、排版台画布）导出 PDF / Word / PPT，逐页目视。
- `npx tsc --noEmit` 干净、`npx vitest run` 96 条全过、15 条路由 `console-sweep` issues=0。

## 已知限制

- Word 不复刻画布位置。
- PDF 里超长标签会被收成一行省略号。
- 画布里正文格留白大时，导出那块框就是空的 —— 那是画布本身的留白。
