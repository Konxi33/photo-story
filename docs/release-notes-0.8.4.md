# 照片故事 0.8.4

把导出排版又修了一遍，你在真实项目上试出来的四个问题都落到了代码里。

## 这一版修了什么

**日期真的关得掉了。** 上一版只关了封面那一处，总览页里那句「共 N 张 · 生成于 年月日」还在照旧打印——你看到的那张单独一页的日期就是它。现在 PDF 封面、PDF/Word 总览页、PPT 首页都跟着「封面印日期」这个开关走，关掉就一个日期都不出现。

**张数编号全部清掉。** 除了标题旁那个 01，照片网格版式里还有三处：照片左上角的 `01`、「— 图 01 · 标题」这个重复图注、Word 总览缩略图下面的 `01 · 标题`。现在一条都不留，五个版式预设里那个占着左上角的编号格子也直接删了。

**方框终于看得见。** 「有些方框不显示」的真因是颜色写死：框线 `#e6e2d9`、底色 `#faf8f4`，在米白纸（`#fbf8f1`）上跟纸面几乎同色。现在改成跟纸色混出来的三个变量（发丝线 / 浅底 / 更深一档的底），任何纸色下都比纸深一档，夜景纸也不会黑成一团。

**排版不再散。** 积木页从「24 等分格 + 绝对定位」改成「按内容分行带」：每一带的高度按真实文字高度算，间距分三档（标题压图留气口、图注贴图、其余常规行距），装不下先压图、再让解读类块、再降字号，最后才按整句收字。剩下的高度上下平分，整页在版心里居中。

**Word 一图一文不再分家。** 原来是一条行带一张表、表与表之间能自由分页，所以照片和说明会跑到两页。现在整页一张表，每条行带是一行且不允许跨页拆分——照片连同标题、类别氛围、正文、评分要么一起在这页，要么一起翻页。

**积木版照片页有页码了。** 以前只有竖排版有，翻到中间页码会断。

## 升级

0.8.4 安装包直接覆盖安装，项目数据不受影响。装完在导出里把「封面印日期」关掉、纸色选米白，导一次 PDF 看一眼：封面与总览都不该有日期、照片页不该有两位编号、框线应该看得见、Word 里照片和说明应该在同一页。
