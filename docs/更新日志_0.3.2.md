# 照片故事 0.3.2

发布：2026-11-06

## 1. 照片评分（100 分制，赛事基准）

- 每张照片给出 **overall + 六个小项**：构图 25% / 光线 20% / 主体 20% / 调色 15% / 时机 10% / 技术 10%
- 总分不是模型随便给的：**按权重重新计算**，再走一条**赛事校准曲线**
  模型 90 → 84（入围）、80 → 72（好片）、70 → 60（记录）、60 → 48（有明显问题）
- 提示词里加了「先列 3 个扣分点再给分」「六项全 ≥88 必须下调最低三项」的反虚高自检
- 同时给出 **scoreAdvice**：针对扣分最多的小项，2–3 条可执行建议
- 界面：预览里显示大号总分 + 六条权重进度条 + 建议
- 实测：同一张测试图，模型原始 91.3 → 校准后 **82.0**，小项拉开差距（84 / 78 / 81.6 / 86.2 / 80.4 / 79.2）

## 2. 修复深色模式闪白

根因不是 CSS，而是**主题挂载时序**：`<html>` 上的 `data-theme` 要等 React 水合后才设置，首帧和路由切换都会先画浅色底；随后 `AppShell` 又用默认值把它覆盖回浅色。

修法：

- `layout.tsx` 在 `<head>` 注入同步脚本，**首帧绘制前**就读 localStorage 打好 `data-theme` / `data-glass`
- `AppShell` 的初始状态也同步读 localStorage（不再先默认浅色）
- 外观统一收敛到 `src/lib/appearance.ts`（`applyAppearance`），只此一处写 DOM + localStorage
- 设置页开关**实时预览**，不用保存就能看到效果

## 3. 修复玻璃模式（三层 + 3D + 可调模糊）

- 旧版用 58% 透明底，内容看不清；现在**三层玻璃**：
  · L1 侧栏/页面容器 92%（深色 88%）
  · L2 卡片/按钮 90%（深色 84%）
  · L3 弹窗/下拉 96%（深色 92%）
  三层都带 `backdrop-filter` 与内高光，有厚度而不是透明
- **3D 悬浮**：玻璃模式下按钮/链接 hover 时 `perspective(900px) translateY(-2px) scale(1.012)`，按下回弹
- **模糊强度可调**：设置 → 外观 → 玻璃模糊 6–40px，写入 `--glass-blur`，三层按比例缩放
- 顶栏、侧栏、卡片、弹窗全部覆盖

## 4. 修复切换界面跳屏

- `html { scrollbar-gutter: stable }`：预留滚动条宽度，不再因为滚动条出现/消失而横向抖一下
- 转场容器加 `overflow-x: clip` + `contain: paint`，位移不再制造滚动条
- `body { overflow-x: clip }` 兜底

## 5. 照片库改为「中心扩散」

以鼠标所在照片为圆心，按**欧氏距离**衰减（不再是方形网格距离）：

- 中心：放大 1.18、亮度 +14%、饱和 +6%、白色光晕
- 四周：`scale = 1.18 - 0.085 × 距离`、`brightness = 1.14 - 0.13 × 距离`、`opacity = 1 - 0.14 × 距离`
- 越远越小幅、越暗、越淡，形成 ColorOS 手表应用列表那种聚焦感

## 6. 导出排版模块化

之前 Word/PDF/PPT 都是「一行行文字往下排」，现在改成模块：

- **Word**：参数条 → 五格小表（焦段/光圈/快门/ISO/调色，带底纹与细边框）；评分卡 → 左大数字 + 右侧六项分行；三块建议 → **并排三列卡片表**
- **PDF**：参数 chips、评分条（`break-inside: avoid`）、三列建议卡
- **PPT**：参数行 + 右下角评分徽标
- 预览页也补了评分模块，编辑页保存时不再丢失新字段

## 7. 顺带修掉

- `globals.css` 曾被 PowerShell 写成 GBK，中文注释与**中文字体名全变乱码**（`宋体` → `瀹嬩綋`）→ 已重写整份文件，字体回退恢复正常
- 背景光斑颜色原先由 JS 判断主题，水合前后不一致 → 改成 CSS 变量（`--blob-1/--blob-2`）驱动
- 清理：删除 0.3.0 安装包 zip、旧版更新日志、tsconfig 缓存

## 9. 请手动确认

1. 设置 → 外观：打开深色，再开玻璃，拖动模糊滑条，看是否即时生效、切换菜单是否闪白
2. 照片库移动鼠标，效果是否像「中心亮、四周暗」的聚焦
3. 任选照片重新生成，看评分是否拉开差距（不再是清一色 90+）
4. 导出 Word/PDF/PPT，看参数条、评分卡、三列建议是否成模块
5. 菜单来回切换，底部/右侧是否还有滚动条跳动

## 已知限制

- 评分校准曲线是固定映射，不同题材（人像 vs 风光）共用一套水位
- PPT 一页一张、16:9，文字过长仍可能溢出（故事控制在 110 字内可避免）
- 免费模型对「构图/光线」的判断有限，分数只作参考，不必当真
