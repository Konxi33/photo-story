# 0.3.0 · AI 文案系统重做（2026-11-05）

这是照片故事第一个对外可用的版本。

## 新功能

- **6 种标题风格、5 种叙事风格、3 档字数**，同一批照片生成的标题会自动去重，不会十张都叫「夜色」。
- **照片墙**：所有项目的照片集中在一个页面里看。
- **设置页** + **左侧导航**：开始有「一整个软件」的样子。
- **预览升级**：从「一张图 + 一段字」改成「照片 + 文字」的模块化版式，为后面的成书排版打底。
- **导出三种格式**：Word / PPT / PDF，版式可自定义。

## 怎么装

下载本页附件的安装包（只提供 0.5.6 及之后的干净构建），或自行从源码构建：

```bash
npm install
npm run electron:build
```

> 0.3.x 时期的安装包不再提供：那些二进制里编译进了旧的 API Key。
