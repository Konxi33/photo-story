# 照片故事 0.3.5

发布：2026-11-07

## 1. 修复设置二级菜单「向左抖」

原因：二级菜单用的是 `<a href="#look">`，点击会改 URL hash 并触发浏览器锚点滚动；在 sticky 导航 + 转场容器里，这一次额外滚动会和容器位移叠加，表现为横向抖动。

改法：改用 `button` + `scrollIntoView({ behavior:'smooth', block:'start' })`，不碰 URL，也不产生额外滚动。

## 2. 补全菜单/浮层动效

之前下拉、选择器只有 `animate-in` 标记，没有具体位移与时长，观感仍偏生硬。现在：

- 下拉菜单：淡入 + 缩放 95% + 按方向滑入 1px，150ms
- 选择器：淡入 + 缩放 + 侧滑 2px，150ms
- 弹窗：淡入 + 缩放（原有基础上补齐关闭态）
- 开关：滑块用 `cubic-bezier(0.34,1.56,0.64,1)` 240ms 回弹
- 按钮/卡片仍保留按下回弹与悬停上浮

## 3. 照片墙按天分组显示时间

- 按「添加时间 / 拍摄时间」分组，组头显示 **今天 / 昨天 / 2026年11月6日 周四**
- 组头右侧显示「N 张 · 添加时间（或拍摄时间）」
- 缩略图悬停时底部补一行具体时刻（HH:MM）
- 排序逻辑不变，分组跟随当前排序

## 4. Ctrl+A 不再选中整页

- 移除了 Electron 菜单里的 `selectAll` 角色（菜单加速键会先于页面生效）
- 渲染进程加了键盘守卫：在输入框、可编辑区域内、或**已打开某个项目**时放行；其余页面拦截
- 复制/粘贴/撤销等其它快捷键不受影响

## 5. 优化 AI 写作与评分口径

写作（`prompts.ts`）新增「获奖作品图注」基准：

- 先写画面细节（光从哪来、什么挡住了什么），再给判断
- 每句话要能指向画面位置，禁止「仿佛/似乎/让人不禁」
- 不用四字词堆砌、不用「治愈」「氛围感拉满」等网络词
- 普通照片就写普通，不硬夸

评分（`scorePrompt.ts`）新增评委口径：

- 获奖作品的共性是「一个不可替代的视觉主张」，按此判断构图/光线/色彩/时机
- 构图看重心与视线路径，不套三分法；光线看体积与层次，不看亮度

## 6. 一键重生成

- 项目工作台工具栏新增 **一键重生成**：对所有已成功照片重跑整篇识别（文字 + 评分一起刷新），换模型后直接用
- 评分页新增 **全部重评**：已评分的照片也覆盖重算
- 原有的单张「重新生成」（编辑器内）与「重新评分」（预览内）保留

## 7. 导出 Word 排版

- 图与文字用 `keepNext` 串成不可拆的块，避免图在一页、文字在下一页
- 图框高度按文字量自适应：文字越多，图越矮（下限 8cm），尽量把一段完整内容压在一页内
- 参数表、评分卡、建议卡的表格行加 `cantSplit`，不会从中间被切断

## 8. 主菜单页（点「照片故事」进入）

新增 `/home`，左栏品牌名改为入口：

- 顶部圆形 logo
- 下方「照片故事」用了**缺笔字**效果：轮廓描边 + 竖向遮罩切掉部分笔画，断裂但仍能读出字形
- 底部一排「项目概览」：封面 + 标题 + 张数 + **总分（不显示细则）**，数量随窗口宽度在 2–6 个之间自适应
- 入场动效：logo / 标题 / 按钮 / 卡片依次淡入上浮
