# 照片故事 0.8.3 更新日志

**这一版只做一件事：把「导出的 PDF / Word」修成印刷厂能直接用的样子。**

0.8.2 之前，导出这条链路的排版一直是「能出来就行」：图片被压得很小、标题旁边挂一个多余的编号、
选了米白纸却只有版心那一块是米白、Word 里照片和说明被分到两页。这一版逐条改掉了。

## 1. 照片页：让照片真的占住版面

以前照片页的图片高度被写死成「版心高度的 46%」，横构图的照片还要再被纸宽削一刀——一张 3:2 的横图
只能占到版心 44% 的高度，剩下 140mm 全是白的。

现在：

- 纵向照片能长到接近整页高（只留上下一点呼吸）；
- 横向照片按纸宽铺满，高度由画幅比决定，这是物理限制，但**剩下的高差由上下留白平分**，不再全部堆在页脚；
- 一页里的「标题 → 图 → 图注 → 正文」当作一整块在版心里居中，眼睛看到的是排版，不是一堆残留空白。

## 2. 去掉两处重复信息

- 照片页标题左边那个浅灰的 `01` 去掉了。它是「技术档案」版式留下的编号习惯，在画册/随笔版式里
  纯粹是噪音。
- 图下面那行 `— 01 雨夜面馆` 也不再重复印标题。图注现在只放真正属于图注的东西（拍摄参数那一类），
  标题已经印在图上方了，再说一遍既乱又冗余。

## 3. 纸面底色铺满整张纸

这是打印的人最容易一眼看出来的问题：选了米白，结果只有中间一块是米白，四周还是打印机的白边。

原因是 PDF 走的是「页面页边距 + 内容上色」——浏览器打印时页边距区域永远是白的，内容画不上去。
现在改成 `@page { margin: 0 }` + 每一页容器自己带纸色与内边距（`width: 纸张宽; padding: 页边距`），
**整张纸从边到角都是一个颜色**。

积木版式（排版台上自己摆的那种）以前连圆角都没有，现在也跟竖排版一样吃「照片圆角」这个设置。

## 4. 日期可以关掉，序号开关真的管用

- 导出对话框新增 **「封面印日期」**：关掉之后封面只留书名与张数。送人的册子不必让
  「2026 年 11 月 28 日」占着封面。PDF 与 Word 都跟这个开关走。
- **「显示序号」** 这个开关以前只影响一部分版面，现在照片页、总览页都听它的。

## 5. Word：不再「图在这页、字在下一页」

Word 的单栏流式排版以前给照片固定 60% 页高，文字一多，照片就被 Word 推到下一页，标题留在上一页。

现在先算文字与标题实际占多少高度，剩下的全给照片（下限 6.2cm、上限 15cm），再按画幅比收一次；
装不下时先让「解读 / 情绪 / 参数」这些次要段落让位，正文与图永远保留。

顺带修掉一个更明显的毛病：**总览页尾部的分页符和第一张照片页的分页叠在一起**，在 Word 里会夹出一整张
白纸——这就是「直接不同一页」的真正原因。现在总览页不再自己补分页符，只由下一页分一次。

Word 的纸色也跟着设置了：米白 / 浅灰会真的印成米白 / 浅灰。墨黑那一档不铺——Word 里正文是深色字，
铺黑会印成一片糊。

## 怎么升级

已经装了 0.8.2 的话：应用启动时会提示有新版本（也可以到设置页点「检查更新」），
装上 `PhotoStory-0.8.3-setup.exe` 即可，项目与照片都在本地，不会动。

## 这一版没做的

- Word 的总览页缩略图还是按原始画幅缩放（竖图看起来偏窄），真正的解法是按格子裁切，
  这会把「总览缩略图」的生成流程也一起改，留到以后。
- Word 不支持图片圆角，这是 docx 格式本身的限制：PDF 里圆角正常，Word 里仍是直角。
- 真正的跨页大图（一张照片横跨两页）需要改 docx 的分节与 PDF 的跨页网格，这一版没碰。
