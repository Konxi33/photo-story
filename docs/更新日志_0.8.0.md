# 0.8.0 · 动效重做成真的 3D，老电脑只关它看不惯的那几块

发布日期：2026-11-27

这一版只有一件事，但把它做透了：**把动效推翻重做**。顺带把几个一直躺着没真正解决的老问题挖了出来——包括那个从 0.7.3 起每次都报、却一直没找到根的水合失败。

## 一、页面转场改成真的 3D

以前的转场是「整页平移 + 模糊」。模糊这一下最贵：`filter: blur()` 会让浏览器每一帧重拍整页，60 帧就是 60 次全页栅格化——看起来就成了「不够丝滑」的样子。

现在改成真的透视转场：

- 舞台给 `perspective(1600px)`，进场页从右侧 `rotateY(5.5deg)` + `translate3d` 转到正面，退场页往左转出去；
- 动的是合成层（transform / opacity），浏览器只挪像素，不重排不重画；
- `animation-fill-mode` 用 `backwards` 而不是 `both`——`both` 会让动画结束后 `position: fixed` 的后代一直留在 transform 上下文里，看着像「跑出屏幕」。

## 二、设置里新增「动效」区

老电脑不该被迫二选一（要么全动、要么全关）。这一版把动效拆成：

**四档强度**

| 档位 | 意思 |
| --- | --- |
| 完整 | 全部动效按原速播放 |
| 平稳 | 时长的 0.8 倍档，动作更短促 |
| 克制 | 0.45 倍，只留必要的位移反馈 |
| 关闭 | 全部瞬时完成 |

**七个区域开关**：页面转场 / 卡片 / 照片墙 / 侧栏 / 弹窗 / 数字滚动 / 背景。哪一块觉得晃，关那一块就行——比如只关「照片墙」的惯性滑动，其他照旧。

还有「全开 / 全关」两个按钮，一次调好。

### 先在设置里试，满意再保存

调档位、关区域都是**立刻生效**的：可以一边调一边看。但它们不写进存储——

- 离开设置页，自动还原成你上次保存的值；
- 点「保存设置」才真正记住（写进 localStorage，同时写 cookie，首帧就能拿到，不闪）。

### 系统级的「减少动态效果」会尊重

Windows 或手机上开了「减少动态效果」，应用会自动降到克制档，不必再自己关一遍。关掉系统开关后，回到你自己选的那一档——存的是你的原档位，不是降档后的结果。

## 三、修掉三个真问题

### 1. React #418：每页都在重画一遍（0.7.3 起一直没真修）

现象：生产包里控制台报 `Minified React error #418`，15 条路由一条不落，整棵树被重画。

根因这次真找到了，而且是同一类错误犯了两处：**在 `useState` 的初始化里同步读 localStorage**。

- 顶栏主题按钮：`useState(readInitialAppearance)` 服务端读到默认值「跟随系统」，客户端读到「浅色」，`title`、`aria-label`、图标（太阳 / 月亮 / 显示器）两边不一样。
- 侧栏折叠状态：`useState(readCollapsed)` 服务端读不到 localStorage，一律按展开渲染；客户端读到 `'1'`，按紧凑渲染。侧栏里几十处 `{compact && …}` 条件渲染，两侧 DOM 结构整个不同——这才是每页都失败的主因。

修法：首帧一律按服务端值渲染，挂载后的 effect 里再补本地值。侧栏那条 effect 还做了一点防闪处理：首轮就用 localStorage 里的值来对齐 `data-sidebar`，以免本来就折叠着的人看见侧栏先展开再收回。因为首帧脚本已经按 cookie / localStorage 画好了主题和密度，晚一帧不闪。

教训（写进代码注释了）：**任何在 useState 初始化里读浏览器存储的写法都会水合失败**，只能放到 effect 里。

复现与验证：`.devtools/probe-dev-hydration.mjs` 会先往浏览器里灌一份「侧栏折叠 + 浅色 + 完整动效」的本地存储，再逐页抓 dev 版 React 的完整差异——比生产包里那句 `#418` 有用得多。修前 /home 能直接打出 `<aside>` 的 className 差异，修后 14 条路由全是 0 条消息。

### 2. 设置页一次报 15 条「同一个 key」

路由进度条和页面容器是同一个父级下的两个兄弟，都用了 `key={pathname}`。给进度条换成 `key={'bar-' + pathname}` 就干净了。

### 3. 动效倍数第一帧是 0

`--motion-scale` 这个 CSS 变量还没写上去的时候，`getPropertyValue()` 返回空字符串，`Number('')` 是 `0`——于是第一屏所有 JS 动效的时长都算成了 0：数字滚动直接跳到结果、进场等于没有。

修法：空字符串按 1 处理；同时在服务端渲染的 `<html style>` 和首帧脚本里都补上 `--motion-scale`。

### 4. 标题去重的开关从来没接上

0.7.5 就写了一套「同批标题不许撞车」的收尾逻辑（`src/lib/ai/polish.ts` 的 `isNearDuplicate`），但调用链 `parsePhotoAnalysis → normalizePhotoAnalysis → polishAnalysis` 一路都没把「这一批已经用掉的标题」传进去——那段代码从上线起就在空转，同一批照片里出现「空椅」和「一把空椅」谁也拦不住。

修法：把 `usedTitles` 从 `/api/analyze` 的请求体（`style.existingTitles`）一路传到 `polishAnalysis`。顺带修了两个判据：

- 原来的去重要求被包含的那一方至少 3 个字，两字标题完全逃得过去（「空椅」/「一把空椅」被判成两个不同标题）；现在短的 ≥2 字、长的比短的多不超过 2 字就判重。
- 从正文里补位捞标题时，改成必须过「成句体检」：代词、连接词、「的/了/着/是」收尾一律不要。

### 5. 标题兜底会交出半截从句

标题被剔词剔短之后，代码会从正文里捞一句话补位。条件是「短于 4 字就补」——于是「空椅」这种本来就成立的短标题也被换掉，而且捞出来的是「压着它的还是那块」（原文「压着它的还是那块石头」被拦腰截断）。这条比原来的标题难看十倍。

修法：只在「确实动过这个标题」时才补位；补位结果必须过成句体检。三条测试钉住了：两字标题保持原样、残渣补位不出从句、道具标签仍会被换掉。

## 四、版式统一

13 个页面的标题和说明段原来各写各的字号。这一版收成三套：

- `.ps-page-title`：30px（大屏 34px）、600 字重、行高 1.06、字距 -0.022em，`text-wrap: balance`；
- `.ps-page-title-compact`：26px（大屏 27px），给照片墙、编排这类内容页；
- `.ps-page-desc`：最大行宽 38rem、13px、行高 1.72。

项目首页的英雄区标题故意保留放大，不在这套里。

图标也顺手统一了：lucide 默认 2px 描边在 14 / 16px 上偏重，和正文放在一起显得吵，全站统一到 1.75（`svg.lucide { stroke-width: 1.75 }`）。页面里少数装饰图形是手写 svg 并自己给了描边参数，不受影响。

## 五、翻页预览补上「呼吸页」

只有题记、没有照片的章节，导出里本来就会留一整页白（`buildQuietPage`），但翻页预览里被整段跳过了——书里有、预览里没有。

现在预览也画这一页：上下两条短横线夹一句居中题记，页码照排。同时把「一张纸」的渲染器拆成独立组件 `src/components/book-preview/book-page.tsx`，配了 7 条渲染测试（呼吸页 / 章扉 / 图版 / 附录 / 空半页 / 封面）。

- `src/components/book-preview/__tests__/book-page.test.tsx`：版面渲染，7 条；
- `src/lib/ai/__tests__/schema-title-dedupe.test.ts`：同批标题去重是否真的接上，4 条；
- `src/lib/ai/__tests__/polish-title.test.ts`：标题兜底的成句体检，5 条。

共 33 条，`npm test` 一次跑完约 1.3 秒。

**实测口径**：生产构建 + 静默安装 + 带真实 IndexedDB 的 Edge（1440×950）跑 15 条路由，控制台零 error / 零 warning；动效保存链路用 CDP 点过一遍（调档 → 关区域 → 离开 → 回来 → 保存 → 换页复验）。按项目铁律，全程没有点过任何会消耗 `/api/analyze` 的按钮。

## 怎么升级

下载 `照片故事-0.8.0-安装版.exe`，覆盖安装即可，数据、Key、动效偏好都保留。

装完建议先进「设置 → 动效」看一眼：机器偏老就把「背景」和「照片墙」关掉，只留页面转场，这台机器上会是另一种感觉。
