# 照片故事 0.8.0

这一版把「动」这件事重做了一遍，也把拖了几个版本的水合失败真正修掉了。

## 动效重做成真的 3D

- 页面转场从「整页模糊 + 位移」换成真 3D：新页带透视从右侧转进来、旧页往左退出去。动的是合成层，不再每帧重栅格化整页——这是以前「不够丝滑」的根子。
- **设置里新增「动效」区**：四档强度（完整 / 平稳 / 克制 / 关闭）+ 七个区域开关（页面转场、卡片、照片墙、侧栏、弹窗、数字、背景），全开 / 全关一键。老电脑可以只关它看不惯的那几块，不必整站降级。
- 在设置里调档、关区域都是**先看效果再决定**：立刻生效、离开页面自动还原，点「保存设置」才真正记住。
- 系统开了「减少动态效果」时自动降到克制档；关掉后回到你自己选的那一档。

## 修掉三个一直挂着的真问题

1. **React #418 水合失败**（0.7.3 起号称修过，其实 15 条路由一条不落）：根因是 `useState` 的初始化里同步读 localStorage——顶栏主题按钮一处、侧栏折叠状态一处，后者让服务端与客户端渲染出完全不同的侧栏结构。现在首帧一律按服务端值渲染，挂载后再补本地值。
2. **设置页一次报 15 条「同一个 key」**：路由进度条与页面容器撞了 key。
3. **动效倍数首帧是 0**：CSS 变量还没写上去就被读成 0，第一屏的数字滚动与进场其实一直是「瞬间到位」。

## AI 文案：标题这一块补了两个洞

- **同批标题去重从来没接上**：0.7.5 就写好的判重逻辑没被调用，等于空转，「空椅」与「一把空椅」会并排出现在两页上。现在真正生效，两字标题也不再逃。
- **标题兜底不再交出半截从句**：以前「空椅」这种两字标题会被换成正文里截断的一句（实测「压着它的还是那块」）。

## 版式与细节

- 13 个页面的标题与说明段统一成一套版式（字号 / 字重 / 行高 / 字距 / 行宽），长标题按语感平衡断行。
- 图标描边统一到 1.75（lucide 默认 2px 在 14 / 16px 上偏重）。
- 翻页预览补上「呼吸页」：只有题记、没有照片的章节，导出里有一整页白，预览里也看得见。
- 首页书架在人少时补一个「放入新的一卷」的虚线位。
- 翻页预览的「一张纸」拆成独立组件，配了 33 条自动化测试（`npm test` 第一次真的有内容）。

## 实测（按项目铁律：全程没有点过任何会消耗 `/api/analyze` 的按钮）

- 生产构建 → 静默安装 → 带真实数据的应用（1440×950）跑 15 条路由：控制台零 error / 零 warning。
- 动效保存链路用 CDP 走过一遍：调档 → 关区域 → 离开 → 回来 → 保存 → 换页复验。
- `npx tsc --noEmit` 干净，`npm test` 33 条全过。

## 升级

装完进「设置 → 动效」看一眼：机器偏老就把「背景」和「照片墙」关掉，只留页面转场。
