# 照片故事 0.3.4

发布：2026-11-07

## 1. 独立评分页（侧边栏新增「评分」）

左侧一级菜单新增 **评分**，进入后是跨项目的分数面板：

- 顶部四张概览卡：平均分 / 最高分 / 已评分 / 待评分
- 每张照片一张卡：缩略图 + 标题 + 项目名 + **大号总分** + 六项迷你条形（构图/光线/调色/主体/时机/技术）
- 筛选：全部 / 已评分 / 未评分；排序：分数高→低 / 低→高 / 最近生成；支持搜索
- 卡片直接「开始评分 / 重新评分」；右上角「补评分 (n)」批量处理
- 动效：卡片错峰淡入（每张 35ms）、悬停上浮、按钮回弹

## 2. 项目打包格式 `.zpgs`

项目卡片的「⋯」菜单新增 **打包为 .zpgs**：

- 生成一个 zip 容器：`manifest.json`（项目、照片、分析结果、评分）+ `assets/<photoId>/<variant>.jpg`（原图/预览/AI/文档四档）
- 在另一台电脑上，项目页「导入备份」直接选 `.zpgs` 即可打开（自动识别后缀，旧 `.json` 备份仍兼容）
- 导入时**新建项目并重新分配所有 id**，不会覆盖现有数据；封面、评分、生成文字、选中状态都会保留
- 实测：zip 容器往返字节一致、中文项目名正常

## 3. 顶部菜单收进设置 + 深色统一

- 原生菜单栏（应用 / 编辑 / 视图）**不再显示**——它固定白底，深色主题下非常突兀
- 菜单本身保留（Windows 的 Ctrl+C/V/Z、Ctrl+R、Ctrl+Shift+I 加速键来自菜单角色，直接删会让快捷键失效），只是隐藏了菜单栏
- 新增「设置 → 应用」：重新加载、开发者工具、缩小/放大/恢复 100%、版本信息（含 Electron/Chrome 版本）
- 原生标题栏跟随主题：渲染进程通过 IPC 把 `themeMode` 传给主进程，设置 `nativeTheme.themeSource`，Windows 11 标题栏一起变深

## 4. 跟随系统深浅色

设置 → 外观 → **主题模式**：跟随系统 / 浅色 / 深色

- 选「跟随系统」时监听 `prefers-color-scheme`，系统切换后界面立即跟着变
- 首帧脚本同样按系统偏好判断，不闪白

## 5. 玻璃改成真透明 + 高斯模糊

- 底色从 88–96% 不透明降到 **52–72%**，靠 `backdrop-filter: blur(24px) saturate(200%)` 保证可读
- 三层（侧栏 / 卡片 / 浮层）保留厚度差异，增加**斜向高光渐变**模拟玻璃折射，边缘内高光 + 投影
- 模糊强度可调 8–48px（设置 → 外观）

## 6. 字体方案

设置 → 外观 → **字体**：

| 选项 | 说明 |
|---|---|
| 圆润（默认） | MiSans / 苹方 / 微软雅黑，笔画更圆，替代原来的宋体观感 |
| 系统默认 | 不指定字体，用系统 UI 字体 |
| 宋体 | 传统衬线，保留但不推荐 |

标题（`ps-serif`）原来固定宋体，现在跟随字体方案——默认变成圆润无衬线，不再是通篇宋体。

## 请手动确认

1. 左侧「评分」→ 看概览卡与卡片列表；点「补评分」是否逐张出分
2. 项目卡片「⋯ → 打包为 .zpgs」，把文件拷到另一台电脑，用「导入备份」打开
3. 设置 → 外观 → 主题模式「跟随系统」，切换 Windows 深色/浅色，界面是否跟随；顶部是否还有白色菜单栏
4. 设置 → 外观 → 字体切换「圆润 / 系统 / 宋体」，看整体字形变化
5. 打开玻璃材质，确认背景透出但文字清晰

## 已知限制

- `.zpgs` 用 zip 存储（level 0），体积≈原图总和；大项目导出需要几秒
- 语音/视频类资源不在项目模型内，不会打包
- 字体依赖系统已安装字体；未装 MiSans 时回退到苹方/微软雅黑
