# 照片故事 0.3.6

发布：2026-11-07

## 1. 安装包集成卸载

- 安装器自带 `Uninstall photo-story.exe`，注册到「应用和功能」，卸载项显示「照片故事 0.3.6」
- 开始菜单新增 **卸载照片故事** 快捷方式（应用首次启动时补建，覆盖安装也会补）
- 设置 → 应用 新增 **卸载照片故事** 按钮（带确认弹窗，直接调起卸载器）
- 卸载范围：程序目录、快捷方式、注册表中的卸载项；**照片与项目数据保留**（`%APPDATA%\photo-story`），如需彻底清除需手动删目录
- 实测：静默卸载后程序文件归零、注册表项消失、`ai-config.json` 仍在

## 2. 覆盖安装与运行中提示

- 可执行文件名改为 `photo-story.exe`（ASCII），安装目录仍是 `%LOCALAPPDATA%\Programs\photo-story`，快捷方式仍显示中文
- 覆盖安装时自动清理 0.3.5 及更早的 `照片故事.exe`，不会出现两个主程序
- 运行检测使用 electron-builder 内置的 `CHECK_APP_RUNNING`：软件开着时安装会提示先关闭
- 安装路径固定为 per-user 同一目录，重复安装即覆盖，不会重复占用空间

> 踩坑记录：我最初在 `installer.nsh` 的 `customInit` 里用 PowerShell 检测进程，NSIS 会把 `$_` 当成自己的变量，转义后又触发安装器 0xC0000005 崩溃。后来发现 electron-builder 本身就带运行检测，直接把自写检测删掉了。

## 3. 照片墙时间显示可开关

- 工具栏新增 **时间分组 / 紧凑排列** 切换
- 关闭分组后照片按网格紧凑堆叠，不再被日期头切开
- 选择会持久化（下次打开保持）

## 4. 修复照片墙动效 bug

- **鼠标移出后动效卡住**：改为每张缩略图都监听 `onMouseLeave`，离开即复位
- **向下第 6 张突然变大变亮**：根因是行列计算用「全局序号 ÷ 列数」，遇到日期分组头就错位，某些照片被算成距离 0。现在在分组时直接算出每张的**真实行列**（含每组行数累加），距离计算不再受分组影响
- 衰减曲线同时放缓（每格 0.055），视觉更连续

## 5. 左侧功能栏展开 / 收起

设置 → 外观 → **左侧功能栏**：

| 模式 | 行为 |
|---|---|
| 一直展开（默认） | 固定占位，内容区在右侧 |
| 悬浮展开 | 平时收起，鼠标贴窗口左边缘时整栏滑出并**覆盖**内容区，移开自动收回 |

- 悬浮模式带 300ms 缓动与投影，点击菜单后自动收起
- 底部存储信息、版本号在两种模式下一致

## 6. 更新日志页

- 左侧功能栏「系统」组新增 **更新日志**
- 顶部版本胶囊可跳转，当前版本高亮标记「当前版本」
- 内容为内置数据（`src/config/changelogs.ts`），离线可读，覆盖 0.3.0 → 0.3.6
- 新增版本时只需在数组最前面加一条

## 已验证

- `tsc --noEmit` 0 错误、`next build` 通过
- 安装版 0.3.6.0：`/home` `/changelog` `/gallery` `/score` `/settings` 均 200
- 静默安装 exit 0；卸载 exit 0，程序文件归零、注册表清除、用户数据保留
- 卸载快捷方式：安装后由应用补建成功
- 更新日志页面截图检查通过

## 请手动确认

1. 开始菜单是否出现「卸载照片故事」；点它是否能正常卸载
2. 软件开着时再运行安装包，是否提示先关闭软件
3. 照片库点「时间分组」切到紧凑排列，照片是否连成一片
4. 鼠标在照片间快速移动再移出，动效是否跟手、不卡
5. 设置 → 外观 → 左侧功能栏 切「悬浮展开」，鼠标贴左边缘是否滑出
6. 左栏「更新日志」是否能打开并看到历史版本

## 已知限制

- 卸载后安装目录可能残留一个空文件夹（卸载器自身正在该目录运行，Windows 不允许删自己所在的目录）
- 便携版没有卸载器，卸载按钮会提示「直接删除文件即可」
- 运行中检测依赖 electron-builder 内置逻辑，静默安装（/S）会跳过提示
