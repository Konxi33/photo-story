# 照片故事 0.8.4 更新日志

**这一版是把 0.8.3 没修干净的地方修完：日期真的关得掉、编号全清掉、线框真的看得见、Word 一图一文不再分家。**

0.8.3 改了「照片占多大、纸色铺哪、封面日期能不能关」，但你在真实项目上试出来的事还有四件：

1. 关了「封面印日期」，日期却还在——而且单独占了一页；
2. 照片左上角还有那个张数小数字；
3. 有些方框直接不显示，版面上没有线条框起来的秩序感；
4. Word 里照片和配文不在同一页，虽然有线框，但一张图的说明被拆到下一页。

这四条在这一版逐条落到代码里，并且都用真实用例跑过、逐页看过。

## 1. 日期：一个开关管住所有出口

上一版只关了封面那一处，总览页里那句 `共 8 张 · 生成于 2026 年 11 月 28 日` 还在无条件打印——
你看到的那张「独立一页的日期」就是它（总览页在有些版式里排在封面后面，看起来就是单独一页）。

现在三处都听 `showDate`：

- PDF 封面；
- PDF / Word 总览页（关掉后只留 `共 N 张`）；
- PPT 首页。

## 2. 编号：所有导出路径一条不留

上一版只清了「标题旁那个 01」，照片网格版式（排版台存的积木版）里还有三处：

- 照片左上角的 `01`（`index` 积木，导出时照样画）；
- 图注前面的 `— 图 01 ·`（跟标题重复）；
- Word 总览缩略图下面的 `01 · 标题`。

现在：`index` 积木在所有路径都返回空、图注只印正文、总览只印标题、五个预设里那个占着左上角的
`index` 格子直接删掉（标题因此从第 0 列起、占满整行，不再留一格空白）。

## 3. 线条秩序：让框线跟着纸色走

「方框不显示」的真因不在 HTML，而在颜色：模块框的边线写死成 `#e6e2d9`，底色写死成 `#faf8f4`。
米白纸（`#fbf8f1`）上这两者跟纸面几乎同色，框就「消失」了。

这一版把纸面配色收敛成三个派生变量：

- `--hairline`：`color-mix(in srgb, var(--ink) 26%, var(--paper))`——发丝线，任何纸色下都比纸深一档；
- `--paper-soft`：纸色里混 4% 墨——浅色块、胶囊、评分框的底；
- `--paper-sink`：混 7% 墨——更深一级的底。

所有写死的 `#e6e2d9` / `#faf8f4` / `#f2efe9` / `#8a8a8a` / `#3a3a3a` 都换成这三个变量。夜景纸也不会
再黑成一团：线跟纸一起亮一点，字跟纸一起亮一点。

## 4. 版式：从「24 等分格」改成「按内容分行带」

原来的积木页把 24 行等分成网格，每个块绝对定位到格子里——标题和图之间、图和图注之间就留下一段
跟内容无关的空隙，页面看起来「散」。

现在改成行带排版（`src/lib/export/bands.ts`）：

- 按块的 row 区间切行带，同一行里并排的块算一格；
- 每一带的高度 = 这一带里各块**真实文字高度**之和（用 `text-measure` 量，不是猜）；
- 间距分三档：标题压着照片留一点气口、照片与图注贴紧、其余按常规行距；
- 装不下时按顺序：先压图（保画幅）、再按 `DROP_ORDER` 让解读类块、再降字号，最后才按比例收
  文字高度（`fitText` 按整句缩短，不会切半句）；
- 剩下的高度上下平分，**整页内容在版心里居中**——这就是「不再上面一小条、底下半页白」。

另外，一个块横跨两条行带时以前会在两条带里各画一次，页底就会重复印一整段正文（`grid-full`
用例实测溢出纸底 64mm）。现在块只在它开始的那条带里画一次。

## 5. Word：整页一张表，每行不许跨页

Word 侧原来是「一条行带一张表 + 表与表之间加一个空隙段落」，Word 可以在空隙处自由分页，
所以照片和它的说明天然会跑到两页去。

现在整页写成**一张表**，每条行带是一个 `TableRow`，全部 `cantSplit: true`，行高按同一套行带
算出来的高度给——照片、标题、类别氛围、正文、评分这一组要么一起在这一页，要么一起翻页。

## 6. 页码

积木版照片页以前没有页码（竖排版那边每页右下角都有），翻到中间页码就断了。现在积木页也印页码，
序号跟正文页连续。

## 7. 测试

96 条测试全过（上一版 88 条），新增 `src/lib/export/__tests__/bands.test.ts` 8 条，专门钉住：

- 「横跨两条带的块只画一次」（页底重复正文的事故）；
- 「600 字正文也收在一页之内，不许顶出纸外」；
- 「序号块永远不排」「标题在图上时图注不重复」；
- 「内容少的时候整页垂直居中」。

## 怎么升级

0.8.4 的安装包直接覆盖安装即可，项目数据（IndexedDB 里的照片、书稿、评分）不受影响。
装完之后在「导出」里选你的版式，把「封面印日期」关掉、纸色选米白，导一次 PDF 看一眼：

- 封面与总览页都不该出现日期；
- 照片页上不该有任何两位编号；
- 模块框、图片边框应该看得见；
- Word 里每张照片和它的说明应该在同一页。

如果还有哪一处不对，把导出的 PDF 或 Word 发给我，我按页对着改。
