# 照片故事 0.8.4 更新日志

更新时间：2026-11-28

这一版只做一件事：**把「导出来的文档」做成你在排版台里看到的那样**。之前的问题不是配色或字号，而是导出走了一条和排版台完全不同的排版路径。

## 一、导出跟着排版台的画布走（PDF）

- 排版台里那张 12 列 × 24 行的画布，现在就是 PDF 的版面：标题整行、照片占你摆的那几行、正文/评分/参数/拍摄手法各回各的格子。
- 以前导出会把你的画布当「参考」再重排一遍（等分网格 + 垂直居中），所以同一张照片在排版台和导出里位置完全对不上。
- 新增 `src/lib/export/canvas.ts` 的 `planCanvasPage()`：几何只由 `col/row/colSpan/rowSpan × (列宽, 行高)` 算出，不做二次排版。

## 二、板块之间有框、有标签

- 每个文字板块左边框了一条发丝线、左上角一个小标签：正文 / 评分 / 参数 / EXIF / 标签 / 氛围 / 无障碍 / 拍摄手法。
- 框线颜色跟着纸色混出来（`--hairline = color-mix(in srgb, var(--ink) 26%, var(--paper))`），米白纸上看得见，夜景纸上也不会黑成一团。
- 框起来的空白读得成「一块面板」，不再是散落的白字。

## 三、纸面底色铺满整张纸

两个叠着的 bug：

1. 导出对话框的 `buildSettings()` 漏写 `paper` —— 你选「米白」，这个选择根本没进导出设置，写回项目的永远是默认纯白。
2. Electron 的 `printToPDF` 还带着纸边距，纸色只能铺内容区，四周仍是打印机的白。

现在：`paper` 会进设置并写回项目；`printOptions.margins = { marginType: 'none' }`，页边距改由 HTML 每页的 `.page` padding 负责，纸色从纸边到纸边。

## 四、日期与编号

- 「封面印日期」现在管住所有出口：封面、总览页、PPT 首页。
- 章节标题是日期（`7月15日` 这种）时，不再印页顶那行横线章头 —— 那行字就是你说的「每一页顶上都有日期」。
- 张数编号全部清掉：照片左上角的 01/02、图注前的「— 图 01」、总览缩略图下的「01 · 标题」。

## 五、Word

- 40 页 → 22 页（与导出对话框的预告一致），不再出现「只印着拍摄手法」的空白页。
- 一张照片连同标题、类别氛围、正文、评分落在同一页：照片高度按「这页剩下的高度」算，而不是固定的 60% 页高。
- **不再镜像 12×24 画布**：docx 表格撑不住「整行标题 + 跨 10 行图片 + 精确行高」这种自由网格，试过 `columnSpan/rowSpan`、显式 `tblGrid`、`vMerge continue` 都会把列宽排错。要 1:1 还原请用 PDF。
- 米白以 `w:background` 写进文档；Word / WPS 会显示，用 LibreOffice 系工具转 PDF 时背景会被忽略。

## 六、PPT

- 修掉 `pptxgenjs` 的布局尺寸错配：`LAYOUT_16x9` 实际是 10×5.63 英寸，代码全按 13.333×7.5 排 → 图片比框宽、右栏文字跑到幻灯片外被裁。改成 `LAYOUT_WIDE`。
- 右栏改成游标式排版（标题 → 参数 → 正文 → 总分 → 要点 → 技术档 → 标签），不再用写死的 y 坐标叠字。
- 封面带上第一张照片；底色跟着「纸面底色」走（原来写死 `FBFAF7`）。

## 七、记住上次的导出设置

导出时会把这套设置写回项目，下次打开对话框直接回填：纸面底色、圆角、开关、页边距都在。

## 验收方式

- 用真实项目（20 张、17 个日期章节、排版台 12×24 画布）导出 PDF / Word / PPT，逐页目视。
- PDF 自动化审计（`.devtools/pdfx/cdp-run.mjs`）：`clipped=0 outside=0 clamped=0 badBreaks=0 lineMismatch=0`。
- `npx tsc --noEmit` 干净、`npx vitest run` 96 条全过、`npx next lint` 0 error。

## 已知限制

- Word 不复刻画布位置（原因见上）。
- PDF 里长标签（`#城市天际线 #光…`）会被收成一行省略号，正在改成允许折两行。
- 你的画布里正文格占 6 行、文字只有一两行时，导出来那块框就是空的 —— 这是画布本身的留白，不是排版出错；嫌空可以把格子收紧，或在排版台里换成小一点的正文格。
