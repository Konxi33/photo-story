# 照片故事 0.8.1 更新日志

发布日期：2026-11-27

这一版针对的是「改了跟改了一样」的那些地方：进项目没有转场、照片墙只能拖、翻页预览看完就忘。另外补了三处能立刻感觉到的新东西（帷幕、缩放的墙、放映模式）。

## 1. 进项目有门了

以前点书架上的卡片进项目，是一帧硬切：工作台不套普通页面的外壳，那套 3D 转场根本管不到它。

现在点下去先盖一层纸色帷幕（上面写着项目名，一道铜线拉开），进到工作台再从那里化开。从工作台退回书架同样有过渡，途中那一帧被帷幕接住，看不到白闪。

帷幕只做透明度和位移，不碰 `filter`——0.7.x 那个「整页重拍、60fps 掉到 23」的坑不能再踩。整个效果受设置里「页面转场」区域的开关控制，关掉就是直接切。

## 2. 照片墙能放大了

- 滚轮缩放 0.55–1.9 倍，**以指针压着的那张为锚点**：放大时照片不会从脚下滑走。
- 工具条上出现百分比，点一下回到原尺度；「回到起点」也一起回原尺度并回到正中。
- 墙停下来时，指针压着的那张微微推近一点，像拿放大镜看底片。
- 键盘：方向键推墙（按住 Shift 推得更远）、`+` / `-` 缩放、`0` 或 `Home` 回中、`Esc` 取消选择。舞台本身可聚焦，有铜色轮廓。

## 3. 翻页预览：放映模式

按钮或 `F` 键进入放映：全屏只留纸页、页码和一行快捷键，给客户看稿时不必让对方看见软件界面。

- 点纸页往后翻，方向键照旧。
- 可以开「自动翻页」，每 4.2 秒翻一次，摆着给人看；翻到最后一张会停住，不绕回封面（绕回会让人以为出错）。
- `Esc` 退出，浏览器自己的全屏退出也会把放映层一起收起。

## 4. 翻页预览会记住你看到哪

每个项目各记一份（localStorage `ps:flip:<项目 id>`），下次进来从原处接着翻。如果那几页已经被删掉，会自动收到最后一页。

## 5. 两处小修

- **侧栏底部「设置」旁的细竖条不再压住「设置」**：上面导航列表有 7px 的窄缝给指示条，底部那块没留，指示条画进了「设置」自己的背景。现在两边对齐了。
- **开关更好按了**：轨道还是 34×20，可点区域撑到 36px 高，触控板和手指都不用瞄准。

## 怎么升级

下载 `PhotoStory-0.8.1-setup.exe` 覆盖安装即可，项目与照片都在本地浏览器数据库里，不会动。装完在首页右下角能看到版本号 0.8.1。
