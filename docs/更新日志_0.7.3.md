# 0.7.2 → 0.7.3 更新日志

这一版没有新功能，全在动界面本身：用户说「我让你重构界面，怎么 0.7.2 好像没多大变化」。所以 0.7.3 的题目是——把首页、顶栏、评分页、设置页、项目工作台这一圈全部重排一遍，让打开软件的第一眼就不一样。

## 一、首页整页重写：从「介绍页」变成「书桌」

以前打开首页，先看到一句大标题和一堆说明卡，真正的活儿得自己往下找。现在首页按「你回来要干什么」重新排：

| 位置 | 内容 | 为什么这样排 |
| --- | --- | --- |
| 最上面 | 「继续上次」——封面、项目名、张数、已评分、已选、评分进度条 + 「接着做」 | 九成时间你回来是接着干上一本，不该让你先找 |
| 第二行 | 两张主按钮：新建项目 / 打开成书 | 另外两件事各自一步到位 |
| 第三行 | 四格读数：项目、照片、已评分、平均分 | 想知道「我攒了多少」时不用点进任何页面 |
| 第四行 | 书架（最多八个项目卡） | 项目卡底边有一条铜色细线，长度 = 这册书的完成度 |
| 第五行 | 模式带：八个模块压成一排胶囊 | 想探索的时候再往下走 |
| 最后 | 「照片和文字都留在本机」+ 版本号 | 该说的安心话放最后 |

- 「继续上次」的来源：进过哪个项目就记一笔（`localStorage['ps:last-project']`）；没有记录就取最近改过的那个项目。
- 原来首页那张扇形卡堆和「光圈」渐层全部撤掉了——它们好看但不解决任何问题。

## 二、顶栏：从一行灰字改成面包屑

- 左边：分组名做成小胶囊（10px 大写字距）+ 箭头 + 页面名（衬线体 15px）。现在能看出「工作区 › 照片库」这种层级。
- 中间：搜索从「搜索 / 跳转」小按钮换成真正的搜索框，写着「搜索照片、页面、动作」，右边还带 `Ctrl K`；窗口窄了才退回图标。

## 三、评分页：四张卡变一张「体检卡」

原来第一屏是四张并排的读数卡，下面才是直方图，再下面是雷达——三块各自占地方。现在合成一张卡：

- 左列（232px）：平均分 42px 大字、已评/总数、最高分、待评。
- 右列：分数分布（横跨）+ 维度雷达（236px）。
- 已评分不足三张时，右列改成一句「再评几张照片，这里会长出分数分布和维度雷达」，不再摆一张空白图。

顺带把「导出评分表」按钮挪进分布那一栏，和它服务的数据在一起。

## 四、设置页：宽屏左侧常驻导航

- `xl` 以上：分组导航搬到左边竖排常驻（吸顶），滚到哪一节左边就亮哪一节（铜色竖线），正文从 `max-w-3xl` 放宽到 `max-w-5xl`。
- 窄屏：仍然是顶部那条可横向滚动的胶囊，行为不变。
- 两处共用同一份 `NAV_ITEMS`，以后加分组只改一个地方。

## 五、项目工作台：新增「项目体征」条

进项目后，页头下面多一条细带：照片数、已生成、已评分、已选，右边一条生成进度。以前这些数得往下看状态栏或者自己数，现在进门就知道走到哪一步了。

## 六、顺手修的与顺手加的

- 更新日志每一节改成滚到眼前再浮上来（`.ps-reveal` + `animation-timeline: view()`，不支持的浏览器直接静态显示）。
- 深色下首页的暖光/冷光压到 55%，不再在纸面上盖一层灰。
- 修掉一个「每次打开都在抛」的水合错误：主题切换按钮在首帧就去读 localStorage，服务端没有、客户端有，React 判定首帧不一致（#418）并整棵树重画；同时把首帧脚本里的 `d.style` 写入也去掉了（`color-scheme` 交给 CSS，`--glass-blur` 交给水合后的 `applyAppearance()`）。
- 版本号 0.7.3，安装包与 GitHub 同步。

## 怎么升级

1. 下载 `PhotoStory-0.7.3-setup.exe`，按默认路径装（会覆盖旧版，项目与照片都在 `%APPDATA%\photo-story`，不会丢）。
2. 打开后先看首页的「继续上次」——你最近那本书应该就在最上面。
3. 宽屏用户可以进设置看看左边的常驻导航。

## 下一步候选

- 排版台的积木面板还能再收一收（现在一页放不下时要滚）。
- 照片库的网格视图还没有虚拟化，几千张时会卡。
- 导出的「技术档案」版式还缺页眉。
