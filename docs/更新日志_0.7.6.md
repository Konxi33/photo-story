# 0.7.6 · 标题写这张照片的局面，不写里面有什么

发布日期：2026-11-25

这一版只盯一件事：**标题别再像零件清单**。

以前的模型看到车里有一块蓝牌，标题就写「蓝牌的车」；看到副驾驶上放了个玩偶，就写「副驾驶的玩偶」。它念的是画面里的一件东西，换到任何一张拍到它的照片上都成立，等于没写。

这一版把标题的写法整个换掉：先读整张照片的局面——什么时辰、什么天气、人和东西怎么摆、动作走到哪一步、空气里是什么感觉——再取一个 4 到 10 字的标题。

## 一、标题：从「念零件」改成「说局面」

提示词里给了六种取景法，模型只能从这六种里挑：

| 取景 | 例子 |
| --- | --- |
| 时刻与光 | 「四点后的斜光」「天光刚落到台阶上」 |
| 天气与空气 | 「雨停之前」「风把雨棚掀起来」 |
| 距离与位置 | 「隔着两条车道」「从七楼往下看」 |
| 关系 | 「他走在前面，狗跟在后面」「左边在等，右边走了」 |
| 动作进行到哪 | 「还没关上的门」「正要开走」 |
| 声音与温度 | 「喇叭按了两下」「冷得没人愿意停」 |

「蓝牌的车」「副驾驶的玩偶」「桌上的杯子」这三条被当成反例，直接写进提示词、写作规则和交付前自检里：把标题念给一个没看过照片的人听，如果他只能听出「有一辆车」「有个玩偶」，就重写。

## 二、不靠模型的防线：认得出道具标题

模型偶尔还是会偷懒，所以润色层加了一道机械检查：

- **认得出**「某物 + 的 + 某物」这种标题（约 70 个常见道具词：车、车牌、后视镜、方向盘、玩偶、招牌、杯子、台阶……）。
- **换得掉**：从这篇正文里挑一句有局面的短句换上。挑的时候按分数排序——有局面词、有时态标记（没 / 还 / 正 / 刚 / 要）、有天气或光、长度 4 到 10 字加分；每出现一个道具词扣两分。
- **说得清**：换了会记一条说明「道具标签式标题，改从正文取局面」，不会悄悄改。
- **不误伤**：合格的标题原样保留，「雨停之前」「刚熄火，车灯还亮着」「隔着两条车道」都验过不动。

实测：

| 原标题 | 改后 |
| --- | --- |
| 蓝牌的车 | 车灯还亮着 |
| 副驾驶的玩偶 | 车灯还亮着 |
| 方向盘 | 车灯还亮着 |

同一个故事里兜底出来的句子会重复，所以同批重名时会再取一句别的局面句，实在没有才用序数兜底。

## 三、正文：开头也不许点零件

故事硬指标新增一条：开头写这帧的局面，不点名画面里的某件东西。不再允许「副驾驶的玩偶坐着」这种零件清单式起笔；可以先说时辰、天气、人和东西怎么摆、动作走到哪一步，再落到具体那件东西上。

## 四、照片详情里多了一个不花钱的出口

标题旁边加了「从故事里取一个」：不用调模型、不花一分钱，直接从这篇故事里挑一句像标题的短句填上去，并告诉你挑了哪句。碰到哪张照片标题不满意，点一下就换，不用整批重新生成。

## 五、版面语言：区块开始有分节感

- 区块小标题前面压一道铜色短规矩线，区块之间用发丝线收口——项目页的「我的项目」先按这一行说话。
- 书架里最近在做的那一本，标题改用衬线，和页首大标题同一套语言。
- 照片墙的方块滑条在深色主题下多了一圈描边，铜点不再糊进纸里。
- 标题里保留一个逗号：「刚熄火，车灯还亮着」这类并列句不再被机械压平。

## 怎么升级

下载 `PhotoStory-0.7.6-setup.exe`，装到原目录，数据、Key、设置都不用重新配。装完打开，进照片详情点「从故事里取一个」，先看几张效果。

## 下一步候选

- 让模型在生成时就知道这一批里其它照片写了什么，避免整批都从同一类局面起手。
- 标题的「局面」可以再分档：远景讲距离、近景讲质感、夜景讲光。
- 排版台里给标题留字号档位（现在标题统一 16pt，长标题会挤）。
