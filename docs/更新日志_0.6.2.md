# 0.6.2 · 少一层盒子，多一分清爽

## 一、设置页瘦身

以前：十个分组，每个都是一张带圆角、带边框、带内边距的卡片，一个接一个叠下来，像十个抽屉；每个选项的标签还压在控件上方，一屏只能看到四五个选项。看过去确实「冗杂」。

现在：

- 卡片墙换成**一条分隔线 + 标题 + 一句说明**。标题是主，说明是次，两者分行。
- 选项改成**左边名称、右边控件**的表格式排列。一行一件事，眼睛可以只扫左边那一列找自己要改的东西。
- 整个页面短了近一半，滚动条不再一路拖到底。

## 二、这一版还带上了 0.6.1 的全部排版修复

由于 0.6.1 的修复是逐步做出来的，0.6.2 里包含它们全部：

1. **章头计入网格高度**：以前章头是在表格外面单独加的，网格不知道这页顶上还有字，仍按整页排 —— 两者一加超出一页，整块被推到下一页，前一页只剩章头，就是那张「白纸」。20 张照片印成 37 页，修好后 22 页。
2. **竖排按真实文字高度分行**：以前按经验高度估，估多了下半页就空着、照片被压成一小块。现在按实际字数算行数，剩下的行全部给照片。
3. **同一页只用一个字号**：不再出现小格子 7.5pt、大格子 11.5pt 的拼贴感。
4. **挤不下时按优先级让位**：无障碍 → 氛围 → 标签 → 类别 → 机身 → 参数 → 建议 → 评分，依次省略，并在导出报告里写明省掉了哪一块，不再悄悄截断。
5. **写字前先算格子能放几个字**：给模型的要求里写明「这一页正文约多少 cm 宽、能排几行、最多多少字」，按这个数写，印出来就不会被切。

## 三、顺手把界面上「多余的噪音」也收了

这几条都是同一个思路：**常用的留在明面上，不常用的收进去，为 0 的不显示。**

- 导出对话框：`纸张方向 / 页边距 / 正文分栏 / 正文行距 / 总览列数` 收进「更多选项（…）」。日常只看到格式、封面、总览、纸张、装订线、排版密度、图片质量、一页印什么、方案、输出位置。
- 照片卡：有 AI 标题时，文件名改成**悬浮才出现**，卡片首屏只留一个标题（没有 AI 标题的照片仍然直接显示文件名）。
- 「批量生成」「补评分」后面的计数为 0 时不再显示，界面里不会再飘着一个孤零零的 0。
- 模块说明卡：默认只留一行提要 + 三步上手，长解释收进「细说」，第一次进排版台/评分这类页面不再被一大段文字挡住。

## 四、怎么升级

下载 `PhotoStory-0.6.2-setup.exe` 直接安装，覆盖旧版本，项目、照片、评分、排版方案都在本地，不会动。
