## 一、标题字数可以自己定了

以前字数在提示词里写死，用户没法改。现在：

- **设置 → 写作 → 标题字数**：四个预设（一个词 1–4 字 / 短 2–8 / 中 4–12 / 长 6–18）+ 自定义最少、最多（1–24）。
- **工作台的写作风格面板**里也有同一处开关，三个风格预设各带了合适范围（图注 2–8、随笔 2–10、纪实 2–8）。
- 最多字数是**硬约束**：模型超了会被按逗号 / 破折号 / 空格 / 「的」处截断，截不动就硬截到上限。最少字数交给模型，不硬撑——把一个词的标题拉长成一句话，比短更糟。
- 这个范围会进提示词（「标题字数：2–8 字」），也进清洗层；请求 schema 里同样校验，不依赖前端。

## 二、标题还像半句话，本地当场改写

提示词写「不要写成完整句子」，便宜模型照样会交「压着它的还是那块」。所以加了一层确定性的收尾器（`src/lib/ai/title-doctor.ts`）：

- **句式判定**：一条标题归到 无题/编号、地名+时刻、并置、单一实物词、专名、整句 六种之一。判定依据是开头虚词（它/他/这/那/还是/就是…）、把字句被字句、动词补语（洗得发白）、「的/着/了/在」收尾、逗号后接长段。
- **整句 → 命名法**：判成整句就按当前写法重建成画册目录里的形态。「压着它的还是那块」在「单词」写法下变成「盐」，在「无题/编号」写法下变成「无题 No.07」。重建用的词来自这条片子自己的正文（地点、时刻、实物），凑不出来就退到编号——编号永远成立。
- **套话也拦**：「时光的痕迹」「光影之间」「城市的呼吸」这类抽象词拼句，同样改写。
- **同批去重句式**：一批里同一种句式出现三次，第四张换一种；提示词那边也会被告知「这批已经用过这些句式」。
