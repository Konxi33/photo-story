# 照片故事 0.8.2 更新日志

发布日期：2026-11-28

内容上这不算一个新版本：它把 0.8.1 定稿时那批「标题写法」修好，**版本号变大只是为了让你收到安装包**。

## 1. 为什么要有 0.8.2

0.8.1 发出去之后又改了一处真正要紧的东西（标题生成），重新打了一次安装包。但「检查更新」是装在你机器上的那份程序在做比较，它只比版本号的三个数字：云端 `0.8.1`、你本机 `0.8.1`，它一律回答「已是最新」。已经装了 0.8.1 的人，永远看不到重打的那份包。

所以这次把版本号抬到 0.8.2 ——数字变了，0.8.1 那份旧程序才会算出「云端更新」，把安装包推给你。装上之后，标题才是新的。

顺手给安装包加了个构建标记（写在 Release 正文里，形如 `<!-- build:20261128a -->`），应用会一并比较。以后同一版本再重打修复包，不抬版本号也能被认出来。

## 2. 标题写法整套换掉

以前的六种写法（文学意象、四字凝练、诗性对仗、电影片名、朴素纪实、隐喻象征）名字不同，出来的是同一种东西：四到十字的描述句——「光只到了半条街」「刚拧干的抹布」。单独看还行，一批排在一起就像一个模子刻的，这是「人机、好普通」的来源。

现在换成赛事命名法，六种写法的语感彼此拉得很开：

| 写法 | 例子 | 取法 |
| --- | --- | --- |
| 单词 | 盐 · 守夜人 · 退潮 | 只留一个词，不解释 |
| 无题 / 编号 | 无题 No.04 · 码头习作 12 | 放弃命名权，用编号与习作名 |
| 地名与时刻 | 青石桥，清晨五点 · 北岸，十一月 · 七楼，雨后 | 地点 + 时间，像档案 |
| 专名 | 香豌豆—友谊 · 老张的船 · K 记冰室 | 把画面里的东西当作品名 |
| 引语 | 向晚意不适 · 此处禁止停留 · Mala tempora | 借用诗句、标语、谚语 |
| 并置 | 一盏灯，一条空街 · 椅子与雨 | 两个名词并排，不给结论 |

依据是公开的赛事与画册目录：Sony 摄影奖 2024 的《Moonrise Sprites over Storr》《Spiralkampagnen》、IPA 的《Love》《Mala tempora currunt》、中文名录《视界》《瞬息之诗》《道路中隐藏的秘密》《香豌豆系列—友谊》。它们的共同点不是「有画面感」，而是**短、不解释、可核对**。

硬规则跟着改了：

- 1–14 字；可以只有一两个字，可以带数字、破折号、空格、拉丁字母。
- 不许写成描述完整的句子——「光只到了半条街」不合格，要交「半条街」或「无题 No.07」。
- 不许道具标签（「蓝牌的车」），不许解释寓意，不许加书名号引号，不许用「氛围感 / 静谧 / 治愈系」这类空泛词。
- 三个候选都用指定的那一种写法，不许混着给。

## 3. 标题不再被事后改坏

- 清洗只删句子级标点（`。；！？…`），**保留** `·`、`—`、`：` 和空格——以前会连 `—` 一起删掉，「香豌豆—友谊」「无题 No.04」都被改坏过。
- 长度上限从 10 字放宽到 14 字，超了先找逗号 / 破折号 / 空格处断，断不了才硬截。
- 「单词」「无题 / 编号」这两种写法生成的一个词标题，不会再被「像道具标签」那条规则事后改写成散文句。
- 设置页与工作台的写作风格面板，每种写法下面直接给出例子，选之前就知道会得到什么。

## 4. 测试与环境

- 单测 73 条（本版新增更新判定 9 条：版本更高 / 同版本重打 / 标记一样 / 老包无标记 / 没有 tag 都钉住）。
- `npx tsc --noEmit`、`npx next lint` 与打包安装、全路由控制台巡检（15 条路由零报错）都过。
- 老规矩：本轮所有实测都没有点任何会消耗模型额度的按钮。

## 5. 怎么升级

设置 → 关于 → 检查更新，会看到「有新版本 v0.8.2」，点下载并安装即可；也可以直接去 Release 页拿安装包覆盖安装。数据和书稿都在本机，覆盖安装不会动。
