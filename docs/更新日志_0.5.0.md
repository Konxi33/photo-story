# 照片故事 0.5.0 更新日志

> 版本号：0.5.0　发布日期：2026-11-11
> 一句话：**会挑片，也会看水平。**

这一版把「生成完一堆照片之后还得自己挑」这件事做掉了，同时把上一版几处看得见的毛病都修了（包括上一版新加、但从没真正显示出来的分布图）。

---

## 一、新增功能（10 项）

### 1. 智能精选
工作台「更多」→「智能精选」，选 6 / 9 / 12 / 18 张，一键成组。
- 先按总分从高到低排；
- 同一个题材（标签第一项，没有标签就看氛围）最多占 `⌈目标数/3⌉`，避免整本都是晚霞；
- 高分不够时自动回填剩余名额，不会出现「只选了 4 张」的空档。

### 2. 按分数选片
「更多」→ 按分数选择：`≥80` / `≥70` / `≥60`。会先清空原有勾选再选，并提示选中了几张。

### 3. 评分维度雷达图
评分页右侧新增雷达图，构图 / 光线 / 调色 / 主体 / 时机 / 技术六轴。
分数挤在一起时，光看平均分看不出问题，雷达图一眼就能指出哪一维塌下去。

### 4. 评分表导出 CSV
评分页「导出评分表」，文件名 `照片故事-评分表-YYYY-MM-DD.csv`。
带 UTF-8 BOM，Excel 双击打开中文不乱码；含项目、标题、文件名、总分、六个维度。

### 5. 快捷键清单（按 `?`）
任何时候按 `?` 打开：全局 / 项目内 / 照片库与评分 三组，含 Ctrl+K、Ctrl+N、Ctrl+,、Ctrl+A、Esc 等。
在输入框里按 `?` 不会触发，不会打断打字。

### 6. 设置「未保存」提示
改了任何设置，右上角按钮变成「有改动未保存」，并开始拦截关闭窗口。
保存成功后提示自动消失。

### 7. 筛选新增「已选」
只想看已勾选的照片时，不用滚动找，筛选里直接选「已选」。

### 8. 成书体量预估
导出前体检里多了一行：入选张数 / 正文字数 / 预估页数。
避免导完才发现整本只有 6 页（或厚得像砖）。

### 9. 评分卡显示「对比均值」
每张评分卡的总分下面多了 `+6.0 对比均值`，高于均值绿色，低于均值灰。
分数有了参照系，74.7 到底是好还是差，一眼能判断。

### 10. 工具栏「更多」菜单
一键重生成 / 复制全部文案 / 补评分 / 按分数选择 / 智能精选 / 删除所选 / 全部删除 收进一个菜单，
把原本挤成两行的工具栏压回一行。

## 二、优化（15 项）

1. **侧栏指示条不再漂移**：原来底部存储用量异步加载后会多长出一行，把「设置」往上顶 34px，而指示条位置停在挂载时。现在用 `ResizeObserver` + 逐帧校正持续跟随。
2. **分布图终于看得见了**：上一版的柱子用百分比高度，但父容器高度是 auto，`height:70%` 被解析成 0，一根柱子都没有。现在给了确定参照高度。
3. **分布图张数常显**：不用悬停才知道每档多少张。
4. **分布图不再被右侧雷达图拉长**：改成顶部对齐，卡片按内容高度。
5. **上传区收成窄条**：已有照片时只留一行（`拖入照片或点击添加 … 选择照片`），首屏多出一整行照片；拖拽时才展开。
6. **工具栏单行**：批量生成 / 全选·反选 / 搜索 / 更多 / 视图 / 列数 / 筛选 一行排完。
7. **「补评分 (0)」不再常驻**：没缺项时不显示，有缺项才显示数量并显示在菜单里。
8. **「导出 Word」改名「导出成书」**：实际支持 Word / PPT / PDF，按钮文案与能力一致，悬停有说明。
9. **状态栏空闲不再挂 0% 进度条**：改为「全部就绪 / 还没有照片」，看起来不像坏了。
10. **进度条无障碍语义**：`role="progressbar"` + `aria-valuenow`，百分比 `aria-live="polite"` 朗读。
11. **窄屏顶栏高亮修复**：进入 `/projects/<id>` 后顶部图标也能正确高亮（原来用全等匹配，子路由一律不亮）。
12. **焦点环统一**：Tab 键 2px 焦点环，鼠标点击不出现。
13. **数字等宽**：分数、张数、百分比统一 `tabular-nums`，跳动时不抖。
14. **照片懒加载**：`loading="lazy" decoding="async"`，长项目首屏更快。
15. **照片库分类 chip 不再被裁切**：换行而不是横向溢出。

## 三、修复

- 侧栏指示条比选中项低 34px（见优化 1）。
- 评分分布直方图完全不可见（见优化 2）。
- 工作台上传区常驻 ~90px 空白。
- 工具栏被挤成两行。
- 底部状态栏 0% 进度条。
- 手机/窄屏顶栏图标高亮缺失。

## 四、安装说明

- 安装版：`照片故事-0.5.0-安装版.exe`（推荐，自动建快捷方式，可静默 `/S`）
- 便携版：`照片故事-0.5.0-便携版.exe`（免安装，直接双击）
- 覆盖安装即可，**项目与照片不会丢**（数据在 `%APPDATA%\photo-story\data`）
- 本机已装 0.4.x 的，直接跑新版安装包覆盖，无需先卸载
