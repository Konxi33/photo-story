# 照片故事 0.6.0 —— 一张 A4 纸，积木自己摆

> 发布日期：2026-11-18

0.5.7 把「一页印什么」做成了竖着的一列开关，能调顺序、能关掉某一块，
但这不是你要的东西。这一版把它推翻重做：**给你一张 A4 纸，把积木摆上去。**

---

## 一、这一版在做什么

一句话：**每一页长什么样，交到你自己手里；摆错了，AI 会告诉你。**

| | 0.5.7 | 0.6.0 |
| --- | --- | --- |
| 版面 | 一列竖着的开关，只能排序 | 一张 A4 画布，14 块积木随便摆 |
| 块的位置 | 由上到下堆叠 | 12 列 × 24 行网格，摆哪印哪 |
| 块的大小 | 固定 | 拖动右下角，跨行跨列自由 |
| 检查 | 无 | AI 检查 + 给一版修正 |
| Word 实现 | 段落流 | 一页一张 12×24 无边框表格 |
| 放不下 | 溢到下一页 | 先缩字号，再截断并说明 |

---

## 二、排版台（新页面：左侧「创作 → 排版台」）

一张 A4 版心的画布，格线淡淡的，只在编辑时看得见，**不打印**。

- **十四块积木**：照片、序号、标题、图注、正文、机身信息、拍摄参数、评分卡、
  点评与改进建议、拍摄手法、图片类别、标签、氛围、无障碍描述。
- **拖动块身**挪位置，**拖右下角**改大小，松手自动吸附到格子。
- **块不能互相压住**：撞上会原地弹回，画布不会乱。
- **八套模板**开箱可用：摄影集、参赛投稿、技术档案、杂志对开、极简画册、
  图文随笔、明信片、完整档案。点一下换整套，再手动微调。
- **撤销 / 重做**各 40 步，改坏了随时退回。
- **实时试算**：每一块的实际字号、会不会被截断、图片最高能占多少厘米，摆的时候就能看到。
- 摆好点「保存排版」，存进项目；导出时自动用这套。

## 三、AI 会看你的排版

点「AI 检查」，模型会：

1. 先看有没有排错——照片框比例不对、正文行数不够会截断、留白太空、同类块该合并；
2. 说人话告诉你问题在哪（每条不超过 30 字）；
3. **直接给一版修正后的排版**放到纸上，不满意一键撤销。

安全闸门在服务端：模型给的排版必须过硬校验（12×24 网格、不越界、不重叠、
积木一块不多一块不少、id 必须一一对应），**只要有一条不合法就整块丢掉**，
只把问题说给你听，绝不把排坏的版式写进导出。

## 四、Word 导出现在真的按画布铺

- 一页 = 一张 **12 列 × 24 行的无边框表格**，跨行跨列用单元格合并实现；
- 单元格内边距为 0、行高精确到 twip，LibreOffice 与 Word 渲染一致；
- **放不下先缩字号**（11.5pt 一路降到 7.5pt），还放不下就截断，并在页面上说明；
- **一张照片连它的文字永远只占一页**，不会被拆到两页。

## 五、PDF 导出用同一套摆位

PDF 走绝对定位：`colW = 版心宽 / 12`、`rowH = 页高 / 24`，按毫米还原画布，
和 Word 出来的效果对得上。章注换行时会按实测文字高度让位，不会把整页顶出去。

## 六、修掉的一个隐蔽白页

网格页是「整页一张表格」。表格前后夹一个 run 级分页段落时，
LibreOffice 会在表格后多印**一整张空白页** —— 19 张照片印出 39 页。
改成分页写在段落属性上（`pageBreakBefore`），页数回到 22 页。

## 七、老项目不受影响

没有画布的项目，导出仍走 0.5.x 的竖排版式，一个字都不会变。
只有你第一次在排版台点「保存排版」之后，才切换到积木版。

## 八、老电脑更快了

这一版顺手做了三件和「老机器」有关的事：

- **首屏 JS 变小**：图标库改成按需引入（`optimizePackageImports`），只打包真正用到的图标，启动与页面切换的解析量都降下来。
- **设置里终于能调这两个数**：「传给 AI 的图片长边」和「本地缩略图长边」以前写死成 1024 / 640，界面上看不见。现在在「设置 → 性能」里可以选 768 甚至 480，老电脑调小一档，识别和翻照片都会明显跟手。
- **清理脚本**：`npm run 之类的命令` 之外，仓库里带了 `node scripts/clean-cache.mjs`，默认只列出可删的构建缓存（`.next`、`dist-electron`、`.shots`、临时安装包副本），加 `--apply` 才真删，**不会碰安装包、照片和源码**。

## 九、顺手做的

- **清理脚本**：`node scripts/clean-cache.mjs` 默认只列表，加 `--apply` 才删；
  只清能重新生成的东西（`.next`、`dist-electron`、截图、Temp 里的安装包副本），
  默认不碰 `安装包/`、`data/`、你的照片和文档。这次清出 1.4 GB。
- 相框水印里的参数不再印「推测 135mm」「ISO ISO 200」这类字样。
- 自动更新改成拉版本列表按语义化版本取最大（GitHub 的 `releases/latest`
  指向最近创建的那个，不是版本号最大的）。

## 怎么升级

1. 下载 `PhotoStory-0.6.0-setup.exe`，双击安装（会覆盖旧版本，数据都在）；
2. 打开后左侧「创作 → 排版台」，挑一个项目，先套「摄影集」模板看看效果；
3. 拖几块试试，点「AI 检查」看它怎么说，满意就「保存排版」；
4. 回项目页「导出成书」，Word / PDF 都会按你摆的来。

## 这一版没做、留给下一版的

- 排版台的多页模板（现在只定义「每一页照片」长什么样，封面/总览/章节页仍是固定版式）；
- 跨页对图（一张图横跨订口）；
- 镜像页边距（内白 ≠ 外白）；
- 总页数自动补到 4 的倍数；
- 排版方案单独导出/导入，分享给别人。
