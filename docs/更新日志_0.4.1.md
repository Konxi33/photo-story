# 照片故事 0.4.1

发布：2026-11-08

## 一、修复

### 1. 侧栏选中块改成「黏合」动效

- 切换选项时，小块先沿路径**拉长**（像拉丝/粘液），覆盖「旧位置 → 新位置」的整段
- 到站后再**收回**成与当前选项等高的圆角块（4px 宽、全圆角、带轻微投影）
- 两段分别用 110ms 快出 + 360ms 回弹曲线，不再是生硬平移

### 2. 折叠后切换选项又展开

- 根因：折叠状态只写 IndexedDB，页面切换会重挂载 AppShell，异步写入还没落盘，新实例读回旧值
- 处理：折叠状态**同步写 localStorage**（`ps:sidebar-collapsed`），重挂载立即恢复；IndexedDB 仍作为跨端备份

### 3. 快速切换时小块跑到「本地存储」

- 根因：用 `getBoundingClientRect` 测量，页面转场有 transform，会测到中间态坐标
- 处理：改用**布局坐标**（`offsetTop` 逐级累加，忽略 transform），并限定只在真实菜单项之间移动；本地存储区不再参与测量

## 二、新增功能（2 个）

### A. 命令面板（Ctrl+K）

- 随时唤起，搜索页面、项目、快捷操作
- 键盘操作：↑↓ 选择、Enter 打开、Esc 关闭
- 项目结果直接跳项目，带张数提示
- 顶部有搜索框与分组标签，条目有悬停/选中态

### B. 一键复制全部文案

- 项目工具栏新增「复制文案」
- 把标题 + 正文 + 评分（有的话）按「———」分隔拼成纯文本，写入剪贴板
- 适合贴到公众号、朋友圈、笔记软件；没生成时给出提示

## 三、优化（5 处）

1. **折叠状态持久化**：localStorage + IndexedDB 双写，切换页面不丢
2. **指示条测量机制**：布局坐标代替视口坐标，转场中不再漂移
3. **命令面板键盘流**：全键盘可完成「搜索 → 选择 → 跳转」，不用鼠标
4. **快捷键体系**：Ctrl+K 面板、Ctrl+N 去项目、Ctrl+, 设置
5. **侧栏折叠按钮**：常驻模式可用、悬浮模式置灰并给出原因提示；折叠后顶部保留原位展开按钮

## 二次修复（同日，0.4.1 重新打包）

用户反馈三个 bug 仍在。这次先用 **CDP 真机点击** 复现，结论和改法：

### 1) 滑块「不够圆润 / 生硬」

- 近距离切换：先轻微拉丝（最多 +26px），再收缩到与选中项等高，420ms `cubic-bezier(0.16,1,0.3,1)`，宽 5px 全圆角
- 长距离切换（超过 320px）：不再拉长滑过整栏，改为**先淡出、落位后淡入**
- 这样从「项目」跳到「设置」时，细长条不会扫过「本地存储」

### 2) 折叠后切页又展开

CDP 实测：状态本身是持久的（切页后仍是 64px），真正的问题是 **重挂载瞬间先按展开态画了一帧**。处理：

- 折叠状态同步写 `localStorage` + `html[data-sidebar]`
- 首帧前脚本（layout.tsx）提前写入 `data-sidebar`
- CSS 在 `html[data-sidebar=compact]` 下直接收窄侧栏、隐藏文字
- 实测：折叠后切页 `w=64 / labels=0 / ds=compact`

### 3) 滑块跑去找「本地存储」

根因同 1：跨整栏拉长 + 用视口坐标测量。已改为布局坐标 + 长距离淡入淡出。

## 三次修复：滑块真正的根因

之前一直没修好，是因为**每个页面各自渲染 `<AppShell>`**，导航时侧栏整个重建：
新实例从零开始，指示条直接出现在新位置，根本不存在"移动过程"，所以怎么调曲线都生硬。

处理：把上一次的位置记在**模块级变量**里（`lastIndicatorValue`），新实例先按旧位置初始化，
再滑到当前项。现在从「项目」点「设置」实测有 18 个中间帧：

```
120 → 114 → 303 → 575 → 665 → 783 → 821 → 872 → 889 → 912 → 937 → 940
```

- 近距离/远距离都走「先轻微拉丝（封顶 24px）→ 滑到目标 → 收回等高圆角块」
- 位置用布局坐标，不受转场 transform 影响
- 长距离不再把整条拉到目标底部，所以不会盖住「本地存储」

更新日志也补进安装包了（之前只改了源码没重新打包，所以应用里看不到）。
